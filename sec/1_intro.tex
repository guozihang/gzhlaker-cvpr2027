\section{Introduction}
\label{sec:intro}
Video copy localization (VCL) returns the pairs of temporal intervals at which a query and a
reference video show the same content. It is a pairwise task, not library retrieval: copies can
be cropped, overlaid, re-encoded or speed-changed, so both interval endpoints and the temporal
mapping between them must be recovered~\cite{vcsl2022,transvcl2023}. With fixed pretrained
descriptors, comparing all frame pairs of sequences of lengths $M$ and $N$ costs $MN$ cosine
similarities per pair. Sparse-to-tube pipelines avoid most of that cost by discovering a few
correspondences, fitting temporal tracks, and refining only a narrow band around each track.

FastVCL follows this pattern. A stride-4 grid supplies mutual top-1 ISC matches; RANSAC keeps
geometrically consistent tracks; each track defines a band; and a local dynamic program aligns
frames inside the band. The strict operating point (cosine 0.70, five inliers, eight tracks) is
deliberately conservative. It yields few false anchors, but it also decides that a copy exists
\emph{before} the band is examined. A short copy, an edited middle, or a copy whose frames match
only weakly can fail the anchor stage entirely, and no boundary refinement can recover it. Two
decisions therefore remain outside the strict core: (i) is a weak temporal correspondence a real
copy that strict matching missed, and (ii) given an admitted copy, where does it start and end?

\paragraph{Two structured decisions.}
We answer both with a pretrained decision interface (JEV) that consumes numeric evidence and
returns a scalar probability or one identifier from a finite option set. The interface never
emits coordinates or segment scores, never overrides a geometric gate, and is not given video
frames in the version studied here. For recovery, a shadow RANSAC pass relaxes only the support
threshold and re-fits tracks on the same anchors. A hard gate removes tracks whose slope,
bounds, support, order, residuals or gaps are impossible; a probabilistic question then
estimates whether the remaining track is a copy, and only tracks above 0.75 are sent to the
tube. For boundaries, every segment, strict or recovered, receives at most five candidates (keep,
extend left, extend right, extend both, shrink), each revalidated against local features; a
multiple-choice question selects one, with confidence at least 0.65, and otherwise the original
boundary is kept. The refined segments are then merged through a dual-axis deduplication that
treats two intervals as duplicates only when they overlap on \emph{both} axes. One query interval that maps to two
different reference locations therefore survives as two copies.

\paragraph{Why decisions rather than more matching.}
The historical ablations in Section~\ref{sec:exp} show the trade-off directly. Relaxing the
stride to 1 with two inliers raises recall from 14.36 to 31.15 and F1 from 24.91 to 45.79;
per-frame argmax reaches recall 59.73 but precision collapses to 9.12, and TransVCL reaches
R 40.19 at B 84.13 under its own protocol. More anchors thus buy recall, but they also multiply ambiguous matches on
repeated textures, logos and similar shots. A decision layer is attractive only if it can
separate the additional true copies from the additional false ones at a cost far below dense
matching. This is the hypothesis we formalize and test, not a result we assume.

\paragraph{Research questions.}
\textbf{RQ1 (recovery).} Does shadow recovery add true copies without raising false alarms
beyond a matched rule-based control on the same candidate pool? \textbf{RQ2 (boundary).} Does
boundary choice improve interval accuracy over keeping the original boundary and over
rule-based candidate selection? \textbf{RQ3 (multiplicity and cost).} Does dual-axis
deduplication preserve one-query/many-reference copies under a fixed per-pair decision budget,
and what do the questions cost in calls, tokens and latency? Each question has a stated
falsifier in Section~\ref{sec:exp}.

\paragraph{Contributions.}
(i)~\emph{Architecture:} a strict sparse-to-tube localizer augmented with two discrete decision
stages, hard geometric gates, fail-closed thresholds and per-output provenance; the strict
system is recovered exactly when the interface is disabled. (ii)~\emph{Mechanism:} same-anchor
shadow recovery with a Noul admission test, dual-axis dedupe that preserves multi-copy
instances, and C0--C4 boundary candidates with feature revalidation and a Choice fallback.
(iii)~\emph{Protocol:} a reproducible specification of the strict branch, a 27-row historical
diagnostic (24 internal runs plus three external baselines), an F0--F3 ladder, eight controls,
and multi-copy/boundary/cost metrics. The
new ladder is specified but not yet executed; historical diagnostics motivate the design, and
no accuracy or latency gain is claimed.

\paragraph{Scope.}
Recovery consumes the same anchor set as the strict branch: it re-fits tracks with a lower
inlier requirement but does not run an independent loose sparse matcher, so it cannot recover
evidence absent from the strict anchor pool. The interface sees numeric track evidence, not
frames. All JEV rows use batch size one. These boundaries are stated again where they affect a
claim.
