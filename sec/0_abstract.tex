\begin{abstract}
Video copy localization identifies corresponding temporal intervals within a pair of
untrimmed videos. With fixed pretrained frame descriptors, the cost of dense comparison
grows with the temporal product, even when only a few intervals are copied. We formulate
\emph{FastVCL}, a training-free downstream localizer that separates candidate discovery
from boundary refinement. Sparse mutual Top-$K$ correspondences propose local temporal
tracks; support checks and gap splitting define finite tubes; a zero-floored local dynamic
program searches only within those tubes. The design exposes three questions: whether
sparse proposals retain short copies, whether local alignment improves boundaries, and
whether reduced alignment work translates into lower measured latency. We specify controls
against a simple sparse-to-band baseline, distinguish executed arithmetic from memory
savings, and define a common evaluation and timing protocol. A separate proposed visual
verification branch, named \texttt{seltive model}, requires original frames and is not
included in the fixed-feature comparison. The current prototype differs from the proposed
restart rule, and no frozen benchmark comparison is available.
