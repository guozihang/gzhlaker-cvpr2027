\subsection{Data and selection protocol}
\label{sec:exp-data}
The audited local VCSL release~\cite{vcsl2022} contains 12,254 fixed ISC feature files,
97,033 training pairs, 41,798 validation pairs and 54,630 test pairs. Validation is
positive-only; the test list contains 27,315 GT-key-missing pairs, treated as negatives by
the local loader. These are release-specific counts. Coordinates are half-open feature
indices, not seconds or source-video frames. We preserve original GT and separately count
degenerate/out-of-range annotations; the supplement records file hashes and anomalies.

Choose structural settings on development data and each method's threshold on validation with
a predeclared grid, objective and tie rule; freeze before test. No test score may select or
sweep. Validation is selection-biased, and because it has no negatives it cannot calibrate
test FAR; a separate negative set needs documented provenance, otherwise FAR is held out.
Audit shared videos across splits before treating pairs as independent.

\subsection{Metric and completion accounting}
\label{sec:exp-metric}
For predictions $P_k$ and GT boxes $G_l$, define $O_k^A$ as the union of A-axis projections
of their positive-area intersections, and $O_k^B$ analogously. Let $Q_l^A,Q_l^B$ reverse
the roles. For nonempty predictions and GT, the reference evaluator computes
\begin{equation}
\begin{aligned}
P_p&=\frac{\sum_k\ell(O_k^A)}{\sum_k\ell(P_{k,A})+\epsilon}
     \frac{\sum_k\ell(O_k^B)}{\sum_k\ell(P_{k,B})+\epsilon},\\
R_p&=\frac{\sum_l\ell(Q_l^A)}{\sum_l\ell(G_{l,A})+\epsilon}
     \frac{\sum_l\ell(Q_l^B)}{\sum_l\ell(G_{l,B})+\epsilon},
\end{aligned}
\label{eq:metric}
\end{equation}
where $\epsilon=10^{-6}$ and $\ell$ is interval length. These are products of axis coverage,
not min-IoU or area IoU. Empty predictions with nonempty GT return $(P_p,R_p)=(1,0)$;
nonempty predictions with empty GT return $(0,1)$; both empty return $(1,1)$.
The evaluator excludes exactly-one values separately from each mean. Write
$\mathcal D_P=\{p:P_p\ne1\}$ and $\mathcal D_R=\{p:R_p\ne1\}$; then
\begin{equation}
\bar P=\frac{\sum_{p\in\mathcal D_P}P_p}{|\mathcal D_P|},\quad
\bar R=\frac{\sum_{p\in\mathcal D_R}R_p}{|\mathcal D_R|},\quad
\mathrm{F1}=\frac{2\bar P\bar R}{\bar P+\bar R+\epsilon}.
\label{eq:macro}
\end{equation}
The additive $\epsilon$ means an ordinary nonempty perfect overlap scores slightly below 1
and remains in the average; it must not be described as automatically excluded. The final
$\epsilon$ in \eqref{eq:macro} is the evaluator's zero guard: it is negligible for positive
means and makes F1 zero when both means are zero. Preserve source dtype and equality
semantics. Report an empty macro denominator as undefined, not zero. Legacy confidence
filtering uses $q>c$ except that $c=0$ takes the no-filter branch; record that mode and
integer-coordinate conversion explicitly.

Each run reports four denominators: \texttt{n\_expected}, \texttt{n\_processed}
(\textsc{ok}+\textsc{empty}), $|\mathcal D_P|$ and $|\mathcal D_R|$, plus failures,
skips and counts excluded by equality. Only complete zero-error runs enter the main table.
An exception is never converted into an empty prediction. Correctly rejected negatives
contribute to neither macro mean, so separately report test negative-pair FAR: the fraction
of the 27,315 negatives producing at least one segment. Validation FAR is \texttt{N/A}.

\paragraph{Diagnostics.}
Candidate recall uses tube envelopes: the fraction of valid GT segments with minimum axis
IoU $\ge0.5$ to any envelope. This is a proposal-box diagnostic, not proof of a legal path or
true frame correspondences; freeze the threshold and report the valid-GT denominator while
keeping official scoring unchanged. Boundary MAE averages four endpoint errors in
feature-index units after maximum-cardinality one-to-one matching at the same threshold
(maximize total min-IoU second; deterministic ties); report matched count, recall and a
common-GT cohort to expose survivor bias. Log band dots, DP cell visits and unique covered
cells separately; repeated attempts do not imply recomputed cosines.

\subsection{Baselines and controlled experiments}
\label{sec:exp-baselines}
Classical HV/TN/DP/DTW and compatible pretrained SPD/TransVCL are planned reruns under the
same inputs and evaluator. A checkpoint, feature interface and runnable environment are
prerequisites, not established facts. Other methods remain literature context until their
inputs and protocol can be aligned.

\paragraph{Simple Sparse-to-Band (E1).}
One zero-phase grid, mutual Top-$K$, RANSAC, fixed-width bands, one path per band, and
shared scoring, threshold selection and min-IoU post-processing. The baseline omits gap
splitting and the extra dual-axis support/span checks; its fit still requires distinct A
times. It must use the same recurrence, margin and support rule as the core configuration it
is compared with, so that the named structural change is the only difference. Match
configured coarse work and caps, and report realized candidate counts; only E3 freezes
identical tubes. An improvement is evidence of utility, not proof of novelty.

\paragraph{E0--E5.}
E0 compares external baselines. E1 tests the simple baseline. E2 varies stride, nested
scales and independent phases, reporting candidate recall by minimum GT-axis duration
($<15$, $[15,60)$, $\ge60$ indices) against executed dots; nested $\{2,4,8\}$ is not
equal-budget to stride 2, and unmatched points are reported without an iso-budget claim.
E3 holds tracks and tubes fixed and compares support boxes, band DTW, prototype continuation
and the proposed zero-floor recurrence with common post-processing. E4 varies support,
splitting, de-duplication, $e_A$ and $w_r$ one at a time; the zero-extension row must pass an
explicit A range. E5 compares scan and direct-offset after semantic parity; a full-matrix DP
is a separate search-domain comparison. Five seeds measure fit variability, not data
significance; paired uncertainty must respect shared videos or say that only seed variation
is available.

\subsection{Timing and quality--cost analysis}
\label{sec:exp-e5}
$\Tloc$ starts with raw features resident in CPU memory and initialized operators, and ends
with five-column predictions in memory. Include normalization, transfers, matching, RANSAC,
DP, traceback and post-processing; separate feature I/O, export, initialization and backbone
extraction. Measure the whole pair, including every TransVCL chunk and assembly. Disable
intrusive profiling, warm up, repeat at least three rounds, fix thread counts and synchronize
GPU endpoints. Report wall time, stage residuals, RSS and allocated/reserved GPU memory; only
matched hardware supports an algorithmic speed comparison.

Vary compute-controlling settings such as stride, width and path budget to construct the
quality--cost plane. Thresholds are selected on validation per configuration. A score
threshold applied after localization usually changes accuracy without changing upstream
work, so a threshold-only sweep does not establish an acceleration curve. Freeze the set of
operating points before test access. The reserved quality--cost plane is in the supplement
and remains empty until runs exist.

\paragraph{Evidence limits.}
\label{sec:exp-status}
No row can yet be filled from an admissible run. The audited near-complete development
execution scored 41,797 of 41,798 validation pairs, with one error and an unfrozen
configuration; the run named \texttt{dev1000} scored only 200 pairs in its metrics file.
Synthetic checks establish limited semantics, not real-data accuracy. H1 fails if sparse
proposals lose coverage; H2 is weakened if lower MAE merely reflects lost matches; H3 fails
if proposal or implementation overhead erases the saving. Null findings must narrow the
claim rather than trigger test-driven redesign.
