\section{Experiments}
\label{sec:exp}
\subsection{Protocol and data}
We use the VCSL benchmark~\cite{vcsl2022} with the official validation split (41,798 pairs;
27,315 pairs contain no copy and form the false-alarm denominator) and the official
evaluator for interval matching at tIoU $\ge0.5$. Frames are described by frozen ISC features
($d{=}256$); no network is trained, and every JEV parameter is frozen. A prediction is a list
of half-open interval pairs with scores; an empty list is a valid output, while a crash,
timeout or out-of-memory event is an error and is never rewritten as empty. The prototype has
no access to source videos or a verified frame-index map in this study, so the interface
receives numeric track evidence only; visual evidence is a defined extension, not an executed
condition.

\paragraph{Metrics.}
Accuracy is reported as pair-level precision, recall and F1 at tIoU $0.5$, plus a strict
variant at $0.7$. Boundary quality is measured on true positives by exact endpoint match,
within $\pm1$, $\pm2$ and $\pm4$ frames, and by mean absolute endpoint error. Multi-copy
behaviour is measured by \emph{coverage} (fraction of ground-truth instances with at least two
copies for which all copies are returned), \emph{extra copies} per pair and
\emph{strict-candidate retention} (fraction of strict segments that survive merging and
deduplication). Cost is reported per pair as decision calls, prompt and completion tokens, and
amortized and worst-case latency; peak memory is measured separately. All accuracy rows are
computed on the same 41,798 pairs, and every JEV row uses batch size one.

\paragraph{What the diagnostics motivate.}
Three patterns are stable. First, the strict point is precision-heavy and recall-poor
($B{=}85.52$, $R{=}14.36$): most of its errors are missed copies, not false alarms. Second,
lowering the RANSAC support on the same anchors raises recall to 18.99 while precision falls
to 44.56, which is exactly the trade-off a binary admission test must arbitrate. Third, the
comparison is dominated by the evaluation protocol: per-frame argmax attains $B{=}9.12$ with
$R{=}59.73$, and TransVCL reaches $R{=}40.19$ at $B{=}84.13$ under its own setting. A
$B$--$R$ pair from one protocol therefore cannot be compared with another, which is why all
ladder rows must share one protocol and one negative set.

\subsection{Systems}
\textbf{F0 (strict)} is the frozen branch of Section~\ref{sec:method} with no interface call.
\textbf{F1 (boundary only)} adds dual-axis dedupe and C0--C4 choice to F0.
\textbf{F2 (recovery only)} adds shadow RANSAC, the hard gate and Noul admission, but keeps
original boundaries. \textbf{F3 (full)} adds both. We also run \textbf{F2a}, a gate-only
variant that admits every track passing the hard gate without asking the model, to separate
the value of the gate from the value of the question. The eight controls are: C1, a
deterministic rule on the same candidate evidence (admit when support $\ge3$ and residual
$\le2$; choose the longest verified boundary); C2, random identifiers with the same call
budget; C3, the independent loose sparse branch; C4, doubled decision budget; C5, boundary
choice with recovery disabled; C6, a threshold sweep of 0.60--0.85 for admission and
0.50--0.80 for choice; C7, visual evidence in the state (defined but not executed here); and
C8, prior/suffix stress pairs built by truncating the query before or after the copy. C1--C6
and C8 are executable on the current prototype; C3 requires the optional loose branch, and C7
requires source frames and a verified frame map.

\paragraph{Pre-registered falsifiers.}
For RQ1 we require F2 to improve recall by at least 0.5 points over F0 while increasing the
false-alarm rate by at most 0.10 points and while beating C1 on the same candidate pool; if
the gain disappears at equal call budget, the decision layer is not the cause. For RQ2 we
require F1 (or F3 over F2) to improve exact boundary match by at least two points and to
reduce mean endpoint error by at least 10\%, with strict-candidate retention at or above
98\%. For RQ3 we require two-copy coverage of at least 95\% with no more than 0.2 extra copies
per pair, and a measured per-pair cost below the strict branch's coarse matching cost. A
failed falsifier is reported as a negative result; the design does not get to redefine the
metric after seeing the numbers.

\subsection{Threats to validity}
The historical table shares one feature set and one evaluator, but its rows differ in several
factors at once, so it identifies the recall bottleneck rather than isolating a cause. The
ladder is not run, and its expected effect sizes are hypotheses. The interface's probabilities
are uncalibrated rankings, and the 0.75/0.65 operating points were fixed before the ladder, not
tuned on it. Recovery cannot admit copies absent from the strict anchor pool, so F2's recall
ceiling is the strict candidate pool's ceiling. Boundary labels are interval-level, not dense
frame correspondences, so an exact match is evidence of a correct interval, not proof of a
correct mapping inside it. Finally, batch size one and the absence of visual evidence bound
the cost claims to this configuration.
