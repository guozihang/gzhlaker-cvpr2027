\subsection{Data and selection protocol}
\label{sec:exp-data}
The audited local VCSL release~\cite{vcsl2022} contains 12,254 fixed ISC feature files,
97,033 training pairs, 41,798 validation pairs and 54,630 test pairs. Validation is
positive-only; the test list contains 27,315 GT-key-missing pairs, treated as negatives by
the local loader. These are release-specific counts. Coordinates are half-open feature
indices, not seconds or source-video frames. We preserve original GT and separately count
degenerate/out-of-range annotations; the supplement records file hashes and anomalies.

Choose structural settings on development data and each method's threshold on validation with
a predeclared grid, objective and tie rule; freeze before test. No test score may select or
sweep. Validation is selection-biased, and because it has no negatives it cannot calibrate
test FAR; a separate negative set needs documented provenance, otherwise FAR is held out.
Audit shared videos across splits before treating pairs as independent.

\paragraph{Development splits for the decision layer.}
Development data are grouped by shared videos into \texttt{dev\_design} (structure and
selector), \texttt{dev\_calibration} (action thresholds) and \texttt{dev\_audit} (held-out
check), with overlap to official splits reported. The first target is about 200 real
development pairs covering short copies, strong edits, repeated shots, semantically similar
non-copies and multi-segment copies, plus at least 300 anchor and 150 fusion-edge decisions.
If fewer exist, the count is reported as-is; synthetic samples do not fill the gap. Action
labels require human review or traceable transform truth; model self-labels and ``inside a GT
rectangle'' are weak proxies only, and without reliable labels the actions stay in shadow.
Development negatives never come from the final test list.

\subsection{Metric and completion accounting}
\label{sec:exp-metric}
For predictions $P_k$ and GT boxes $G_l$, let $O_k^A$ be the union of A-axis projections of
their positive-area intersections and $O_k^B$ the analogue; $Q_l^A,Q_l^B$ reverse the roles.
The reference evaluator computes
\begin{equation}
\begin{aligned}
P_p&=\frac{\sum_k\ell(O_k^A)}{\sum_k\ell(P_{k,A})+\epsilon}
     \frac{\sum_k\ell(O_k^B)}{\sum_k\ell(P_{k,B})+\epsilon},\\
R_p&=\frac{\sum_l\ell(Q_l^A)}{\sum_l\ell(G_{l,A})+\epsilon}
     \frac{\sum_l\ell(Q_l^B)}{\sum_l\ell(G_{l,B})+\epsilon},
\end{aligned}
\label{eq:metric}
\end{equation}
with $\ell$ interval length and $\epsilon=10^{-6}$: products of axis coverage, not min-IoU or
area IoU. Empty predictions return $(P_p,R_p)=(1,0)$ against nonempty GT, nonempty
predictions $(0,1)$ against empty GT, and both empty $(1,1)$; exactly-one values are excluded
from each mean, and the macro means and F1 follow
\begin{equation}
\bar P=\frac{\sum_{p\in\mathcal D_P}P_p}{|\mathcal D_P|},\quad
\bar R=\frac{\sum_{p\in\mathcal D_R}R_p}{|\mathcal D_R|},\quad
\mathrm{F1}=\frac{2\bar P\bar R}{\bar P+\bar R+\epsilon},
\label{eq:macro}
\end{equation}
where $\mathcal D_P=\{p:P_p\ne1\}$ and $\mathcal D_R=\{p:R_p\ne1\}$. Report
\texttt{n\_expected}, \texttt{n\_processed} (\textsc{ok}+\textsc{empty}), both macro
denominators, failures, skips and equality exclusions; an empty macro denominator is
undefined, not zero, and an exception is never an empty prediction. Correctly rejected
negatives enter no macro mean, so test negative-pair FAR is reported separately; validation
FAR is \texttt{N/A}. The supplement records the additive-epsilon consequence, the legacy
confidence-filter branch and the exact sentinel handling.

\paragraph{Diagnostics.}
Candidate recall uses tube envelopes at minimum axis IoU $\ge0.5$ and is a proposal-box
diagnostic, not proof of a legal path. Boundary MAE averages four endpoint errors after
maximum-cardinality one-to-one matching at the same threshold; report matched count, recall
and a common-GT cohort. Log band dots, DP cell visits and unique covered cells separately.

\subsection{Baselines and controlled experiments}
\label{sec:exp-baselines}
Classical HV/TN/DP/DTW and compatible pretrained SPD/TransVCL are planned reruns under the
same inputs and evaluator. A checkpoint, feature interface and runnable environment are
prerequisites, not established facts. Other methods remain literature context until their
inputs and protocol can be aligned.

\paragraph{Simple Sparse-to-Band (E1).}
One zero-phase grid, mutual Top-$K$, RANSAC, fixed-width bands, one path per band, and shared
scoring, threshold selection and min-IoU post-processing. It omits gap splitting and the extra
dual-axis support/span checks, but its fit still requires distinct A times. It must use the
same recurrence, margin and support rule as the core configuration it is compared with; only
E3 freezes identical tubes.

\paragraph{E0--E5.}
E0 compares external baselines; E1 tests the simple baseline; E2 varies stride, nested scales
and independent phases, reporting candidate recall by GT-axis duration ($<15$, $[15,60)$,
$\ge60$ indices) against executed dots; E3 holds tracks and tubes and compares support boxes,
band DTW, prototype continuation and the zero-floor recurrence; E4 varies support, splitting,
de-duplication, $e_A$ and $w_r$ one at a time; E5 compares scan and direct-offset after
semantic parity, with full-matrix DP as a separate search-domain comparison. Five seeds
measure fit variability, not data significance.

\subsection{Two decision points (E6)}
\label{sec:exp-e6}
The decision layer is evaluated in six rows, each fixing the correct upstream input.
\textbf{E6-A} (anchor filter) starts from the same serialized $\Anch_0$ and core, and compares
no action, random selection, a margin/geometry rule and time-spread selection at the same
input cap; it reports action errors, downstream candidate coverage, full P/R/F1/FAR,
tracks/tubes/DP work and total cost. \textbf{E6-F} (fusion) starts from the same
$\mathcal C_0$ and legal edge pool and compares no fusion, geometry plus connection only,
random visual and selective visual; it reports wrong bridges, correct and missed merges,
recall, MAE on common GT and cost. \textbf{E6-J} reruns core, A only, F only and A+F on the
same pairs; gains are never added across rows. \textbf{E6-S} compares independent,
ordinary-batch and shared-prefix execution for decision agreement, prefill/suffix time, peak
memory and real sharing fraction. \textbf{E6-R} separates candidate readout from author
post-training and call policy, and \textbf{E6-V} uses real, masked and mismatched frames plus
option permutations to expose language priors and leakage. Budget comparisons report
per-stage resources and a same-total-budget comparison; twelve questions do not cost the same
on different backends. A cheap visual or local-correspondence control on the same frames rules
out a gain from merely seeing more pixels. The full matrix, including fixed inputs and
required denominators, is in the supplement.

\paragraph{Action risk and stopping rules.}
The engineering acceptance targets are a true-copy anchor-deletion rate of at most $1\%$, a
wrong-fusion rate of at most $1\%$, and a final recall drop of at most $0.5$ percentage points
relative to core. These are project targets to freeze, not guarantees; they are read with
confidence intervals and sample size, and zero errors on a small sample do not pass. If no
threshold meets them on \texttt{dev\_calibration}, the action remains in shadow and the
smaller supported conclusion is reported. Filtering that only reduces anchors is not a
success; fusion that only reduces output count is not a success; neither is a score gain on
the selected subset without full-set precision, recall and FAR.

\subsection{Timing and quality--cost analysis}
\label{sec:exp-e5}
$\Tloc$ starts with raw features resident in CPU memory and initialized operators, and ends
with five-column predictions in memory. Include normalization, transfers, matching, RANSAC,
DP, traceback and post-processing; separate feature I/O, export, initialization and backbone
extraction. Measure the whole pair, including every TransVCL chunk and assembly. Disable
intrusive profiling, warm up, repeat at least three rounds, fix thread counts and synchronize
GPU endpoints. Report wall time, stage residuals, RSS and allocated/reserved GPU memory; only
matched hardware supports an algorithmic speed comparison.

For the augmented system, report $\Taug$ as well: it starts before frame reading and includes
decode, evidence assembly, geometry pre-fit, transfer, model calls, retries, connection DP,
score fusion and final output. Cold cache, first-call initialisation and steady state are
separate rows. A warm-cache number may not be compared with a cold-cache baseline, and a
routing-only time may not stand in for the model time.

Vary compute-controlling settings such as stride, width and path budget to construct the
quality--cost plane. Thresholds are selected on validation per configuration. A score
threshold applied after localization usually changes accuracy without changing upstream
work, so a threshold-only sweep does not establish an acceleration curve. Freeze the set of
operating points before test access. The reserved quality--cost plane is in the supplement
and remains empty until runs exist.

\label{sec:exp-results}


\paragraph{Evidence limits.}
\label{sec:exp-status}
No row can yet be filled from an admissible run. The audited near-complete development
execution scored 41,797 of 41,798 validation pairs, with one error and an unfrozen
configuration; the run named \texttt{dev1000} scored only 200 pairs in its metrics file.
No visual backend, verified frame map or action threshold has been validated, and the local
data snapshot contains no source video for the audited feature files, so the decision layer
currently has interface-level evidence only. Synthetic checks establish limited semantics, not
real-data accuracy. H1 fails if sparse proposals lose coverage; H2 is weakened if lower MAE
merely reflects lost matches; H3 fails if proposal or implementation overhead erases the
saving. H4-A fails if filtering deletes true anchors or only reduces work without a quality or
cost benefit; H4-F fails if fusion bridges real non-copy gaps, cannot repair over-segmentation,
or loses to the geometric rule; H4-B fails if the same budget spent randomly or on a cheap rule
matches the selective policy. Null findings must narrow the claim rather than trigger
test-driven redesign.
