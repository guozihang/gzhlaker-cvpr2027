\section{Method}
\label{sec:method}

\subsection{Overview and Problem Formulation}
Given a query video $A$ with $M$ sampled frames and a reference video $B$ with
$N$ sampled frames, Video Copy Localization (VCL) aims to predict a set of
temporal interval pairs $\mathcal{S} = \{[a_s, a_e) \times [b_s, b_e)\}$ that
identify duplicated segments across the two sequences. As illustrated in
Figure~\ref{fig:framework}, \textbf{FastVCL} unifies the classic three-stage VCL
architecture---comprising a frame feature encoder $\Phi_{\rm enc}$, a learnable
similarity matrix $\mathbf{S} \in \mathbb{R}^{M \times N}$, and a
correspondence-map object detector---with a confidence-aware selective model
$\mathcal{M}_{\rm sel}$.

Specifically, $\Phi_{\rm enc}$ maps frames into $d$-dimensional embeddings
$\mathbf{F}^A \in \mathbb{R}^{M \times d}$ and $\mathbf{F}^B \in \mathbb{R}^{N
\times d}$, from which a learnable similarity head computes pairwise affinity
scores $S_{i,j}$. Rather than evaluating dense $M \times N$ correspondence maps
in full, FastVCL operates on a strided anchor grid ($s{=}4$, retaining original
frame indices as coordinates) and splits localization into a fast primary
detection branch and a selective refinement loop:
\begin{enumerate}
\setlength{\itemsep}{2pt}\setlength{\parskip}{0pt}
    \item A \textbf{primary tube detection branch} identifies high-precision
    candidate segments $\mathcal{S}_{\rm main}$ over sparse anchors and refines
    local correspondence bands.
    \item A \textbf{selective track recovery branch} exposes weak candidate
    trajectories via a relaxed shadow pass, filtering them through a geometric
    gate and querying $\mathcal{M}_{\rm sel}$ to admit genuine subtle copies
    $\mathcal{S}_{\rm rec}$.
    \item A \textbf{selective boundary refinement module} generates five
    discrete endpoint hypotheses per segment in $\mathcal{S}_{\rm main} \cup
    \mathcal{S}_{\rm rec}$, updating boundaries via $\mathcal{M}_{\rm sel}$
    under a fail-closed rule before merging duplicates via \textbf{dual-axis
    deduplication}.
\end{enumerate}

\subsection{Sparse Similarity and Primary Tube Detection}
\paragraph{Learnable Similarity and Anchor Proposals.}
To avoid quadratic $O(MN)$ matching overhead, we first evaluate pairwise
affinities $S_{i,j}$ on a stride-$s$ grid ($s{=}4$). For each query grid index
$i$, we retrieve the mutual top-1 reference index $j$ satisfying $S_{i,j} \ge
\tau_{\rm anc}$ ($\tau_{\rm anc}{=}0.70$). This produces a sparse correspondence
set $\mathcal{A} = \{(i_k, j_k)\}$ requiring only $1/s^2$ of dense matrix
evaluations. Over $\mathcal{A}$, a RANSAC trajectory detector fits linear
temporal mappings $j \approx \sigma i + \beta$ with slope $\sigma \in [0.5,
2.0]$ (covering $0.5\times$ to $2\times$ playback speed variations) and retains
high-confidence tracks supported by at least $N_{\rm min}^{\rm strict}{=}5$
inliers.

\paragraph{Band-Limited Detection and Local Alignment.}
Each detected trajectory spanning query frames $[a_0, a_1]$ instantiates a
narrow 2D detection tube over $[a_0 - m, a_1 + m]$ ($m{=}2$) restricted to
reference indices $|j - (\sigma i + \beta)| \le W_{\rm half}$ ($W_{\rm
half}{=}12$). Within this local correspondence band, our detection head resolves
fine-grained frame alignment via a continuity-preserving dynamic program:
\begin{equation}
\begin{aligned}
H(i,j) = r(i,j) + \max_{(\Delta i, \Delta j) \in \mathcal{D}}
\bigl[&H(i - \Delta i, j - \Delta j) \\[-3pt]
&- \lambda_g (\Delta i + \Delta j - 2)\bigr]
\end{aligned}
\label{eq:dp}
\end{equation}
when a valid predecessor exists in the original frame index space, and $H(i,j) =
\max\{0, r(i,j)\}$ otherwise, where $r(i,j) = S_{i,j} - \tau_{\rm dp}$
($\tau_{\rm dp}{=}0.60$), $\lambda_g{=}0.1$, and $\mathcal{D} =
\{(1,1),(1,2),(2,1)\}$. Decoupling continuation from initialization is key to
robust detection: a cell with a valid predecessor retains its accumulated score
even if $H(i,j)$ dips below zero, preventing isolated degraded frames from
fragmenting a continuous copy track, whereas unanchored cells are lower-bounded
by zero so background noise cannot initiate spurious tubes.

\paragraph{Tube Extraction and Detection Score.}
We extract up to four alignment paths per tube by iteratively tracing back from
the highest-scoring cell and masking visited coordinates, allowing shifted or
repeated alignments within the same band to be detected as separate candidates.
Contiguous runs of strong correspondence ($S_{i,j} \ge 0.60$, bridging at most
two weak query frames and trimming weak tails) that span at least three query
frames, four reference frames, and two distinct track anchors form candidate
segments $[a_s, a_e) \times [b_s, b_e)$. Each detected segment is assigned a
detection confidence score combining path affinity and anchor density:
\begin{equation}
q = \alpha \cdot \overline{S}_{\rm path} + (1 - \alpha) \cdot \min\!\left(1,
\frac{n_{\rm anchors}}{\max(1,\, L / \bar{\Delta})}\right),
\label{eq:score}
\end{equation}
where $\overline{S}_{\rm path} \in [0, 1]$ is the mean smoothed similarity along
the alignment path, $n_{\rm anchors}$ is the number of supporting anchors, $L$
is the query duration, $\bar{\Delta}{=}4$ is the nominal anchor spacing, and
$\alpha{=}0.7$.

\subsection{Selective Track Recovery}
\paragraph{Shadow Proposal Generation and Geometric Gating.}
While strict support filtering ($N_{\rm min}^{\rm strict}{=}5$) guarantees high
precision in $\mathcal{S}_{\rm main}$, short or heavily edited copies often
yield fewer surviving anchors. Rather than densifying the entire similarity
matrix, we run a shadow RANSAC pass over the same sparse anchor pool
$\mathcal{A}$ with the support requirement relaxed to $N_{\rm min}^{\rm
shadow}{=}3$ (discarding tracks identical to $\mathcal{S}_{\rm main}$ and ranking
the rest by independent support and span). Before invoking the selective model,
every shadow track must pass a deterministic geometric gate: slope $\sigma \in
[0.5, 2.0]$, at least three distinct coordinates per axis, monotonic reference
ordering, per-anchor residual $\le 4$ frames, maximum consecutive query gap $\le
24$ frames, and minimum span of $4 \times 8$ frames. Geometrically inconsistent
proposals are rejected immediately with zero model overhead.

\paragraph{Fail-Closed Selective Admission.}
Surviving shadow trajectories are encoded into structured geometric-similarity
descriptors---comprising trajectory slope, intercept, support counts, temporal
spans, gap distribution, residual statistics, and anchor coordinates---and fed
into our selective model $\mathcal{M}_{\rm sel}$. Operating as a binary
verification head, $\mathcal{M}_{\rm sel}$ estimates the probability $p_{\rm
copy} \in [0, 1]$ that the weak trajectory corresponds to a true copy. Following
a strict fail-closed rule, a track is routed to the band-limited alignment head
(Eq.~\ref{eq:dp}) to produce a recovered segment in $\mathcal{S}_{\rm rec}$ only
if $p_{\rm copy} \ge \gamma_{\rm adm}$ ($\gamma_{\rm adm}{=}0.75$); otherwise,
it is discarded.

\subsection{Selective Discrete Boundary Refinement}
\paragraph{Multi-Scale Boundary Hypotheses.}
Sparse anchor sampling and local band smoothing can leave residual imprecision
at segment start and end frames. For each candidate segment in $\mathcal{S}_{\rm
main} \cup \mathcal{S}_{\rm rec}$, we project its endpoints through the fitted
linear trajectory and densely re-evaluate local similarity profiles from
$\mathbf{S}$ to construct five discrete boundary hypotheses: \texttt{C0} (keep
initial detector endpoints), \texttt{C1} (extend left), \texttt{C2} (extend
right), \texttt{C3} (extend both), and \texttt{C4} (shrink weak exterior edges).
Extensions are evaluated across step sizes $\{4, 8, 16\}$ and are admissible
only when the projected trajectory aligns within one frame of the original
endpoint and every added frame satisfies $S_{i,j} \ge 0.60$, preventing
extensions from bleeding into adjacent unrelated shots. Shrinking trims only
weak boundary runs (up to 16 frames per side) while preserving all duration and
anchor support constraints.

\paragraph{Confidence-Aware Hypothesis Selection.}
When multiple boundary hypotheses are admissible, we summarize each candidate's
local evidence---mean and median similarity, supported frame ratio, gap and
residual statistics, and interior-to-exterior boundary contrast---and query the
selective model $\mathcal{M}_{\rm sel}$ via a five-way classification head.
$\mathcal{M}_{\rm sel}$ predicts a probability distribution $\{P(\texttt{C}_k)\}_{k=0}^4$
along with an overall decision confidence. The segment boundary is updated to
$\texttt{C}_{k^*}$ ($k^* = \arg\max_k P(\texttt{C}_k)$) if and only if
$\min(\text{conf}, P(\texttt{C}_{k^*})) \ge \gamma_{\rm bnd}$ ($\gamma_{\rm
bnd}{=}0.65$); otherwise, the module falls back to \texttt{C0} while preserving
the detection score $q$ (Eq.~\ref{eq:score}). Because $\mathcal{M}_{\rm sel}$
selects strictly among pre-validated geometric candidates without regressing
unconstrained coordinates, its worst-case fallback is guaranteed not to degrade
the primary detector's localization boundary.

\subsection{Dual-Axis Deduplication and Complexity}
\paragraph{Dual-Axis Merging.}
After boundary refinement, we merge $\mathcal{S}_{\rm main}$ and
$\mathcal{S}_{\rm rec}$ to remove redundant detections. Standard 1D or
product-IoU suppression erroneously collapses valid one-to-many copy patterns
(e.g., a single query clip repeated at two distinct reference timestamps yields
$\mathrm{IoU}_A{=}1$ but $\mathrm{IoU}_B{=}0$). We therefore define duplicate
suppression strictly over the joint 2D temporal correspondence space:
\begin{equation}
\mathrm{dup}(u,v) = \bigl[\mathrm{IoU}_A(u,v) \ge \theta_{\rm iou}\bigr] \land
\bigl[\mathrm{IoU}_B(u,v) \ge \theta_{\rm iou}\bigr],
\label{eq:dedupe}
\end{equation}
with $\theta_{\rm iou}{=}0.80$. Whenever $\mathrm{dup}(u,v)$ holds, only the
higher-scoring segment is retained. This dual-axis criterion is the minimal rule
that collapses shifted duplicate tubes while preserving all one-to-many and
many-to-one copy instances.

\paragraph{Computational Efficiency and Structural Guarantees.}
By construction, FastVCL satisfies three key structural properties: (i)
\emph{coordinate safety}, as all endpoints originate from validated similarity
paths rather than free-form regression; (ii) \emph{geometric pre-gating}, which
eliminates implausible trajectories prior to selective inference; and (iii)
\emph{fail-closed execution}, where low-confidence selective predictions revert
seamlessly to the high-precision primary detector. Computationally, primary
sparse matching requires $MN/s^2$ similarity evaluations and $O(L \cdot W)$
band operations ($W{=}25$) per track, while selective recovery and boundary
refinement introduce at most a small bounded number of lightweight queries (up
to 8 track admissions and 8 boundary selections per pair). Consequently, FastVCL
captures subtle and heavily edited copies with state-of-the-art accuracy while
maintaining sub-quadratic inference speed.
