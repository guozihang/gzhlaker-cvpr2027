\section{Method}
\label{sec:method}
\subsection{Overview and notation}
A pair consists of a query video $A$ with $M$ sampled frames and a reference video $B$ with
$N$ frames, both described by the same frozen frame encoder. A prediction is a half-open
interval pair $[a_s,a_e)\times[b_s,b_e)$ with integer endpoints. The strict branch produces a
set $\mathcal{S}_{\rm main}$ of segments with provenance \texttt{main}; recovery produces
$\mathcal{S}_{\rm rec}$ with provenance \texttt{recovered}. Boundary choice maps each
segment, whatever its provenance, to one revalidated candidate without changing its score;
the refined segments are then merged and deduplicated into $\mathcal{S}$. All coordinates are
original frame indices; the stride-4 grid is only an addressing convention.

\subsection{Strict sparse-to-tube branch}
\paragraph{Anchors.}
Frames are embedded on a stride-$s{=}4$ grid. For each query grid point $i$ we retrieve the
mutual top-1 reference grid point under cosine similarity, keeping pairs with
$\cos(\mathbf{f}^A_i,\mathbf{f}^B_j)\ge 0.70$. This yields a sparse set of correspondences
$\mathcal{A}=\{(i_k,j_k)\}$ whose density is $1/s^2$ of the dense matrix. A RANSAC line fit
$j\approx \sigma i+\beta$ keeps tracks with at least five inliers and slope in $[0.5,2]$,
which covers half-speed to double-speed copies.

\paragraph{Band and local alignment.}
For a track with anchors spanning query frames $[a_0,a_1]$, the tube covers
$[a_0-m,\,a_1+m]$ with margin $m{=}2$ and, for every query frame $i$ in that range, the
reference positions $j$ with $|j-(\sigma i+\beta)|\le 12$. A band cell is \emph{usable} when
$j\in[0,N)$ and the frame pair has a computed similarity; otherwise it is not a match node.
On the band we run the frozen local dynamic program
$H(i,j)=r(i,j)+\max_{(\Delta i,\Delta j)\in\mathcal{D}}
\bigl[H(i-\Delta i,j-\Delta j)-\lambda_g(\Delta i+\Delta j-2)\bigr]$
when a legal predecessor exists, and $H(i,j)=\max\{0,r(i,j)\}$ otherwise,
with $r(i,j)=\cos(\mathbf{f}^A_i,\mathbf{f}^B_j)-\tau$, $\tau{=}0.6$, $\lambda_g{=}0.1$, and
$\mathcal{D}=\{(1,1),(1,2),(2,1)\}$ in \emph{original} frame indices. The distinction between
the two branches is deliberate: a cell with a legal predecessor keeps its continuation even if
the total is negative, so one weak frame does not restart a copy; a cell without one may only
start from non-negative evidence, so a long low-quality stretch cannot be invented from
silence. Predecessor legality is checked on the actual index difference, not on the band's
column offset, because the band samples the original axes irregularly. Invalid cells have
$H{=}0$ and cannot start or continue a path.

\paragraph{Extraction and score.}
The best cell is traced back through the predecessor table chosen during the forward pass,
which makes the traceback an exact replay rather than a second decision. Up to four paths are
extracted per tube: after a path is found, its cells are blocked and the program is solved
again, so repeated or shifted alignments inside one tube become separate candidates. A row is
strong when its smoothed path cosine is at least $0.6$; strong rows form runs that may bridge
at most two weak query frames; leading and trailing weak frames are trimmed; a run must span at
least three query frames and four reference frames and contain at least two independent track
anchors. Endpoints are taken from the actual matched nodes, and the score is
\begin{equation}
q=0.7\cdot\overline{\cos}_{\rm path}+0.3\cdot\min\!\left(1,\frac{n_{\rm anchors}}
{\max(1,\,L/\bar{\Delta})}\right),
\label{eq:score}
\end{equation}
where $\overline{\cos}_{\rm path}\in[0,1]$ is the mean smoothed cosine over the segment,
$n_{\rm anchors}$ counts distinct track anchors inside it, $L$ is its query duration and
$\bar{\Delta}$ the median anchor spacing (default 4). The score depends only on the path and
the track, never on the decision interface, and downstream stages preserve it.

\subsection{Shadow recovery}
\paragraph{Same anchors, relaxed support.}
Recovery re-runs RANSAC on the \emph{same} anchor set with the inlier requirement lowered from
five to three and the track cap raised from eight to twelve; the cosine threshold, stride,
mutual top-1 rule and slope range are unchanged. Tracks whose anchor set equals a strict
track's are discarded, and the rest are ranked by independent support, confidence, span and
coordinates, keeping at most eight. This design is intentional: recovery can admit a copy that
the strict support test rejected, but it cannot invent evidence that the strict anchor pool
does not contain. An independent loose sparse branch exists in the code base but is disabled
in this version, so no result uses it.

\paragraph{Hard gate.}
Before any question is asked, a track must pass every one of the following: finite slope in
$[0.5,2]$ and finite intercept; all anchors inside both videos; at least three distinct query
and three distinct reference coordinates; non-decreasing reference order; per-anchor slope
residual at most four frames; consecutive query gap at most 24; query span at least four and
reference span at least eight. Failures are deterministic and are recorded with a reason; no
model call is made for them.

\paragraph{Admission question.}
A surviving track is shown to the interface as a \emph{Noul} state: pair identifiers, slope,
intercept, support counts, spans, gaps, residual statistics and the anchor list, with visual
evidence explicitly null. The model returns a probability $p_{\rm copy}$ that the track is a
copy of the query content. A track is sent to the tube only when $p_{\rm copy}\ge0.75$;
otherwise it is dropped and the decision is logged. The tube is the same frozen aligner as the
strict branch, so a recovered segment differs from a strict one only in its support and its
provenance. Recovery never deletes a strict candidate by itself: main and recovered segments enter the
same merge, which is applied after each segment has passed boundary choice.

\subsection{Dual-axis merging}
Two segments are duplicates only when they overlap substantially on \emph{both} axes:
\begin{equation}
\mathrm{dup}(u,v)=\bigl[\mathrm{IoU}_A(u,v)\ge0.8\bigr]\land\bigl[\mathrm{IoU}_B(u,v)\ge0.8\bigr].
\label{eq:dedupe}
\end{equation}
Using the minimum of the two axis IoUs (rather than their product or a query-only overlap)
is what preserves multi-copy structure: one query interval that maps to two different
reference locations overlaps perfectly on $A$ but not on $B$, so both survive; the same
reference interval reached from two query locations likewise survives on the other side.
When two segments do duplicate, the higher-score one is kept and the provenance of the
survivor is recorded. This rule is applied once to the union of main and recovered segments after boundary choice,
and the per-pair cap (64) is applied afterwards. Because each track is refined independently,
boundary choice can run on two segments that dedupe later collapses, so a call may be spent on
a duplicate; the survivor is the higher-score segment, and we report the number of segments
judged before dedupe rather than pretending the budget is duplicate-free. Likewise, a strict
segment can in principle be suppressed by a higher-scoring recovered duplicate, so we report
strict-candidate retention as a metric instead of claiming that strict outputs are always
preserved.

\subsection{Boundary choice}
\paragraph{Candidates.}
For each segment produced by a track, in track order and at most eight per pair before
merging, we map its query frames through the fitted track and re-read the local cosine
profile. Five candidates are
considered: \texttt{C0} keep; \texttt{C1} extend left; \texttt{C2} extend right; \texttt{C3}
extend both; \texttt{C4} shrink to the strongly matched interior. An extension is proposed
only when the mapping meets the original endpoints within one frame and when \emph{every}
query frame in the added range has a finite cosine of at least $0.6$; this prevents an
extension from bridging into a different copy whose query coordinates happen to be adjacent.
The extension length is the smallest of $\{4,8,16\}$ that verifies. Shrink removes only weak
edge runs, at most 16 frames per side, and never an interior prefix. Every non-\texttt{C0}
candidate must still satisfy the duration and support constraints of
Section~\ref{sec:method} and may not contain more than two consecutive weak query frames; its
evidence records mean and median cosine, supported fraction, matched counts, independent
support, gap statistics, residual, and inside/outside boundary contrast.

\paragraph{Choice and fallback.}
If only \texttt{C0} is admissible, no call is made. Otherwise the interface receives a
\emph{Choice} state with the five option descriptions and their numeric evidence, and returns
one identifier with a confidence. The choice is accepted when
$\min(\text{confidence},\text{probability of the chosen option})\ge0.65$; otherwise the
segment keeps its original boundary and the record is marked as a fallback. The model never
writes endpoints: it selects an identifier whose coordinates were computed and validated
before the call, and the segment score is preserved unchanged. This fail-closed rule makes
the interface's worst case equal to the strict boundary, which is the property the evaluation
tests.

\subsection{Invariants, provenance and cost}
Four invariants hold by construction. (i)~\emph{No free coordinates:} every endpoint is
derived from features, anchors or the strict path; the interface only selects among
precomputed candidates. (ii)~\emph{Gate before question:} geometric validity is decided
before any model call, and an invalid track or candidate is never shown to the model.
(iii)~\emph{Fail closed:} a missing, malformed or low-confidence answer leaves the affected
item at its strict state. (iv)~\emph{Off means strict:} disabling the interface removes both
stages and reproduces the strict system exactly. Every output carries
\texttt{source}$\in\{\texttt{main},\texttt{recovered}\}$, its boundary choice and a fallback
flag, so each metric can be decomposed by provenance.

The strict branch performs $MN/s^2$ coarse comparisons and, per track, $O(L\cdot W)$ band
cells with $W{=}25$ columns and a constant-size step set. Recovery adds one RANSAC pass over
the same anchors and at most eight binary questions; boundary choice adds at most eight
five-way questions. With $B{=}1$, a pair therefore incurs at most 16 calls, and the token and
latency cost is measured rather than assumed. No new network is trained: all parameters of
the interface are frozen, and the thresholds above are operating points, not fitted values.
