\section{Scope and implementation status}
This supplement details the policy-guided architecture, training targets, measurement protocol,
and historical evidence. The main paper's title and abstract describe the intended system.
No trained checkpoint or benchmark run of that complete system is present in the available
records. The design choices below are a proposed reference specification, not a source-verified
description of an implemented dual-pathway network.

The earlier fixed-feature prototype and its workbook support historical diagnostics only.
Its post-anchor verification and alignment stages are not the front-end policy and trainable
detector proposed here. The present acceleration branch uses direct similarity, anchors,
RANSAC, and bounded endpoint checks; the historical DP configurations are not equivalent.
These distinctions prevent earlier measurements from being assigned to the new method.

\paragraph{Preview construction.}
For length $L$, sample $k=\min(K,L)$ indices uniformly over $[0,L-1]$, retaining the original
order and including both endpoints when $k>1$. Invalid padded positions contribute neither
to means nor to correlations. Their correlations are zero-filled, and their masks remain
visible to the MLP. The input dimension is $2d_p+2K^2+2=770$ for the initial design.
The policy may miss a short copy between sampled positions, so $K$ is a quality--cost
parameter to ablate, not a coverage guarantee. Video decoding and seeking cost are measured.

\paragraph{Main-branch supervision.}
Each interval annotation maps to a normalized rectangle
$(b_s/N,a_s/M,b_e/N,a_e/M)$. A reproducible reference assignment is one-to-one matching of
predicted and annotated boxes using a fixed weighted sum of normalized endpoint distance
and generalized IoU cost. Objectness targets are one for matched predictions and zero for
unmatched predictions; box losses apply only to matches. Negative pairs train background
objectness with zero box loss. Assignment weights, detector output resolution, box
parameterization, and loss normalization belong in the eventual implementation manifest.
This assignment is distinct from the official benchmark evaluator.

\section{Cost-aware policy supervision}
\label{sec:s-targets}
Let $P_b$ be branch $b$'s predictions after its frozen output threshold, and $G$ the annotated
interval pairs. Define interval agreement
\begin{equation}
u(p,g)=\min\{\mathrm{IoU}_A(p,g),\mathrm{IoU}_B(p,g)\}.
\end{equation}
Construct a maximum-cardinality one-to-one matching $\mathcal M_b$ using edges with
$u\ge0.5$, breaking cardinality ties by maximum total $u$, then stable indices. Let
$U_P$ and $U_G$ be the unmatched prediction and annotation counts. The reference training
error is
\begin{equation}
\ell_b=
\frac{U_P+U_G+\sum_{(p,g)\in\mathcal M_b}(1-u(p,g))}
{\max(1,|P_b|+|G|)}.
\label{eq:s-error}
\end{equation}
This quantity lies in $[0,1]$, equals zero for empty predictions on a negative pair, and
equals one for missed positives with no predictions or nonempty predictions on a negative
pair. It is a supervision surrogate, not the official benchmark metric. Its normalization
can affect preferences on multi-copy pairs, so native benchmark metrics remain decisive.

Both branch costs are divided by the same positive training-set reference cost, such as
mean always-main latency. For each held-out training pair, choose main iff
$\ell_{\rm m}+\lambda c_{\rm m}<\ell_{\rm a}+\lambda c_{\rm a}$; choose acceleration on a tie.
If main is both cheaper and more accurate, it is preferred for every nonnegative $\lambda$.
When main is more accurate but more expensive, it is preferred only when its error reduction
exceeds the weighted extra cost. This target does not assume main wins on every hard pair.

\paragraph{Split discipline.}
Partition the training split into branch-fitting and policy-supervision subsets with no
video-identity overlap. Fit the main branch only on the former. On the latter, record both
branches' predictions, errors, and costs before fitting the preview encoder and policy.
Validation selects the operating point; the test split contributes no labels or profiling
targets to learning. If data are insufficient for a disjoint holdout, use cross-fitting with
explicit folds and never silently substitute in-sample branch errors.
Fix branch-specific output thresholds before generating policy targets. If a branch
checkpoint, geometric configuration, or output threshold changes, regenerate the targets
and retrain the policy before selecting its operating point.

\paragraph{Inference contract.}
The deployed predictor has no access to $G$, $\ell_{\rm m}$, $\ell_{\rm a}$, or outputs from
the unselected branch. Offline oracle choices are used only for supervision or diagnostic
evaluation. A thresholded policy makes one routing decision, and the selected branch makes
all interval predictions. If its execution fails, record an error. An empty set from a
successful acceleration run is a valid prediction, even when it is wrong.

\section{Temporal geometry and output semantics}
All anchor coordinates remain in the original sampled-frame index system after grid
subsampling. RANSAC slopes and residuals are measured in that system. For each retained
track, least-squares refitting uses inlier anchors; gap splitting and monotonicity checks
produce supported runs. Multiple accepted tracks can represent multiple copied occurrences.

For an endpoint check, enumerate successive query positions outside the run, stopping after
$s-1$ positions. At each position, search valid reference indices within the residual
tolerance of the fitted line and retain the highest-cosine match if it reaches the threshold
and preserves order. Ties use the smaller reference index. Stop that side at the first
failure. An interval's exclusive endpoint is one sample beyond its last accepted match.
The score is the mean cosine of the run's inlier anchors and accepted endpoint matches.
This is local geometric refinement, not learned boundary selection.

Detector outputs and geometric outputs share the same interval representation. Round lower
endpoints down and upper endpoints up, clip to valid axes, and reject degenerate intervals.
For a supplied sampling map $t_0,\ldots,t_L$, with $t_L$ the terminal video boundary,
$[i_s,i_e)$ maps to $[t_{i_s},t_{i_e})$. Report seconds only when this map is verified.

Sort candidates by score, breaking ties lexicographically by endpoints, and suppress a
lower-score candidate iff both axis IoUs with a retained candidate reach $\tau_{\rm dup}$.
Apply the output cap afterwards. This preserves disjoint reference occurrences, but the
anchor rule, track cap, and segment cap can still limit multiplicity. No recall guarantee
follows from the duplicate rule.

\section{Measurement and ablation details}
\paragraph{Full cost.}
For each pair log preview decoding, preview encoding/policy, selected-branch decoding and
features, similarity construction, detection or RANSAC, post-processing, and serialization.
Do not count reused frames twice; describe the cache and sharing policy. Report raw-video
and cached-feature measurements separately. If only cached ISC features are available,
neither end-to-end training of the image encoder nor raw-video speedup has been evaluated.

The expected cost uses branch-conditional means because routing and runtime can be correlated.
The net saving over always-main is
$\mathbb E[(1-r)(T_{\rm m}-T_{\rm a})]-\mathbb E[T_{\rm p}]$ under equal output accounting.
At $\rho=1$, routing adds overhead to always-main; at $\rho=0$, it adds overhead to
always-acceleration. A successful policy must earn that overhead through better allocation.

\paragraph{Routing controls.}
For matched-utilization controls, fix the target usage on validation and report achieved test
usage rather than retuning thresholds on test labels. The deterministic rule averages
the difference between the largest and second-largest valid similarities per preview row.
If fewer than two valid reference positions exist, route to main. Repeat random routing
over documented seeds and report variation. Include preview cost in policy-isolation
comparisons, and additionally report the random baseline without preview as a deployment
alternative. The oracle requires both outputs and ground truth and has no deployment latency.

\paragraph{Regret and failure reporting.}
For each pair, localization regret is
$\ell_{r(x)}-\min(\ell_{\rm m},\ell_{\rm a})\ge0$, evaluated offline. Cost-aware regret uses
the corresponding error-plus-cost objective and its oracle. Report these separately:
a cost-efficient action may intentionally have positive localization regret. Report
under-routing (acceleration selected when main has lower error), over-routing, and false
alarms with denominators. Annotation-derived strata such as copy duration are for analysis
only, not policy inputs.

\paragraph{Reproducibility manifest.}
Every measured row requires code and checkpoint hashes, split and video IDs, sampling maps,
feature encoder identity, training/validation settings, routing threshold, score thresholds,
all geometric parameters, evaluator version/options, hardware/software versions, timing
scope, random seeds, predictions, and complete run logs. Errors and exclusions must be
reported with their counts. No pending cell can be filled from a partial or incompatible run.

\section{Outstanding evidence}
The proposed policy needs training and held-out routing evaluation; the main branch needs
an implemented trainable encoder, similarity module, detector, and checkpoint. Both VCSL
and VCDB comparisons need complete controlled runs, verified timestamp maps, and matching
timing scopes. The historical local prototype cannot supply these results. The abstract's
accuracy and speedup statements remain unverified until this evidence is available.
