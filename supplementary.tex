\section{Scope and evidence grades}
\label{sec:s-scope}

This supplement records what was verified, what is proposed, and what is missing. It is not an
extra results section. We use four grades. \textsc{source-verified} means checked against the
frozen code or a stored run record; \textsc{proposed} means specified but not executed;
\textsc{implemented-unvalidated} means present in the reference implementation but not shown to
help; \textsc{missing} means no evidence exists. No benchmark result for the F0--F3 ladder is
reported in this draft. The 25 historical rows in Section~4.4 of the main paper (Tables~4 and~5) are
copied from the frozen workbook; they were not rerun, and none of them uses recovery, the
decision interface, boundary choice or dual-axis dedupe.

\section{Strict sparse-to-tube branch}
\label{sec:s-strict}

\paragraph{Anchor grid.} Frames are embedded on a stride-$s{=}4$ grid. For a query grid point
$i$ we keep its mutual top-1 reference point $j$ when $\cos(\mathbf f^A_i,\mathbf f^B_j)\ge0.70$.
No second scale or phase is used, so the anchor set is exactly the one the frozen main branch
produces.

\paragraph{Tracks.} A RANSAC line $j\approx\sigma i+\beta$ is accepted with at least five
inliers, slope in $[0.5,2]$, and residual at most four frames per anchor. Up to eight tracks are
kept. The slope range covers half-speed to double-speed copies; it is a hard validity range,
not a tuned prior.

\paragraph{Band.} For a track spanning query frames $[a_0,a_1]$, the tube covers
$[a_0-2,a_1+2]$, and for each query frame $i$ the columns $j$ with
$|j-(\sigma i+\beta)|\le12$. A cell is usable only when $j\in[0,N)$ and the frame pair has a
computed similarity. Cells outside the band are never scored.

\paragraph{Local DP.} Let $r(i,j)=\cos(\mathbf f^A_i,\mathbf f^B_j)-0.6$ and
$\mathcal D=\{(1,1),(1,2),(2,1)\}$. For a legal predecessor
$(i-\Delta i,j-\Delta j)$ with $\Delta i,\Delta j$ measured in original frames,
\begin{equation}
\begin{aligned}
H(i,j)={}&r(i,j)+\max_{(\Delta i,\Delta j)\in\mathcal D}\\
&\bigl[H(i-\Delta i,j-\Delta j)-0.1(\Delta i+\Delta j-2)\bigr],
\end{aligned}
\label{eq:s-dp}
\end{equation}
and $H(i,j)=\max\{0,r(i,j)\}$ when no predecessor exists; illegal cells have $H{=}0$. The
asymmetry is intentional: a legal predecessor keeps its continuation even when the accumulated
value is negative, so a single weak frame does not restart a copy, while an isolated cell must
start from non-negative evidence. Legality is checked on the actual index difference, not on
the band's column offset, because the band samples the original axes irregularly.

\paragraph{Extraction.} The argmax cell is traced through the predecessor table stored during
the forward pass, so the traceback is an exact replay. After a path is extracted its cells are
blocked and the program is solved again, up to four paths per tube. A strong row has smoothed
cosine at least 0.6; strong runs may bridge at most two weak query frames. Leading and trailing
weak frames are trimmed, endpoints come from actual matched nodes, and a segment must span at
least three query and four reference frames with at least two anchors. The score of
Eq.~(2) in the main paper depends only on the path and the track and is preserved by every
later stage.

\section{Shadow recovery}
\label{sec:s-recovery}

\paragraph{What changes.} Recovery reuses the strict anchor set verbatim. RANSAC is rerun with
the inlier requirement lowered from five to three and the track cap raised from eight to twelve;
cosine threshold, stride, mutual top-1 rule and slope range are unchanged. Tracks whose anchor
set equals a strict track's are discarded. Survivors are ranked by independent support
($\min$ of distinct query and reference coordinates), confidence, span and coordinates; at most
eight continue.

\paragraph{Hard gate.} Table~\ref{tab:s-gate} lists the checks. Every failure is deterministic,
recorded with a reason, and never reaches the model. The gate runs before the admission
question, so a malformed track cannot be rescued by a high probability.

\paragraph{Admission.} The Noul state contains pair identifiers, slope, intercept, support
counts, spans, gap statistics, residual statistics and the anchor list; visual evidence is
explicitly null. The model returns $p_{\rm copy}$, and the track is sent to the tube only when
$p_{\rm copy}\ge0.75$. A missing, malformed or timed-out answer drops the candidate. A recovered
segment differs from a strict one only in its support and its provenance tag; the tube is the
same frozen aligner. Recovery never deletes a strict segment by itself: both enter the same
merge, which happens after boundary choice.

\section{Boundary choice}
\label{sec:s-boundary}

\paragraph{Candidates.} Boundary choice is applied to each segment produced by a track, in
track order, at most eight segments per pair, \emph{before} merging. For a segment with query
interval $[s,e)$ and fitted map $f_r$, five candidates are constructed:
\texttt{C0} keep; \texttt{C1} extend left; \texttt{C2} extend right; \texttt{C3} extend both;
\texttt{C4} shrink to the strongly matched interior. An extension of length
$\delta\in\{4,8,16\}$ (smallest verifying value) is admitted only when the mapped endpoints
stay within one frame of the original reference endpoints and every added query frame has a
finite local cosine of at least 0.6. Shrink removes only weak edge runs, at most 16 frames per
side, and never an interior prefix. Every non-\texttt{C0} candidate must satisfy the duration
and support constraints and contain at most two consecutive weak query frames.

\paragraph{Evidence and question.} Each candidate carries mean and median cosine, supported
fraction, matched query/reference counts, independent support, gap statistics, residual and
inside/outside contrast. The Choice state lists the five descriptions with this evidence; the
model returns one identifier and a confidence. The choice is accepted only when
$\min(\text{confidence},p_{\text{chosen}})\ge0.65$; otherwise the original boundary is kept and
the record is marked as a fallback. The model never writes endpoints and the segment score is
unchanged.

\paragraph{Ordering and budget.} Because each track is refined independently, boundary choice
runs before dual-axis dedupe. Two segments that dedupe later collapses can therefore both be
judged, and a call can be spent on a duplicate. Dedupe keeps the higher-score survivor, so the
loss is bounded by score ties; we report the number of segments judged before dedupe and the
number of calls, rather than assuming a duplicate-free budget.

\section{Dual-axis deduplication}
\label{sec:s-dedupe}

For segments $u,v$ let $\mathrm{IoU}_A$ and $\mathrm{IoU}_B$ be the intersection-over-union of
their query and reference intervals. We call them duplicates iff
$\mathrm{IoU}_A\ge0.8$ and $\mathrm{IoU}_B\ge0.8$. The conjunction is what preserves
multiplicity: a query interval mapped to two different reference locations overlaps perfectly
on $A$ but not on $B$, so both survive; the symmetric case survives on the other axis. Using
the product or the query-only overlap would collapse such pairs. When two segments do
duplicate, the higher-score one is kept and its provenance is recorded. The rule is applied
once to the union of main and recovered segments; the per-pair cap of 64 is applied afterwards.

\paragraph{Falsifiers.} RQ1 requires F2 to improve recall by at least 0.5 points over F0 while
raising the false-alarm rate by at most 0.10 points, and to beat C1 on the same candidate pool.
RQ2 requires F1 to improve exact boundary accuracy by at least 2 points and reduce mean endpoint
error by at least 10\% over F0, while retaining at least 98\% of strict segments. RQ3 requires
two-copy coverage of at least 95\% with at most 0.2 extra copies per pair, and a measured cost
below strict coarse matching. A failed falsifier is reported as a failure.

\section{Evaluation protocol}
\label{sec:s-eval}

\paragraph{Data.} VCSL validation, 41{,}798 pairs, of which 27{,}315 are negative. Metrics are
computed at tIoU 0.5; the historical diagnostics span the same evaluator. All JEV rows use batch
size one so that a call is a per-pair decision, not a batched score.

\paragraph{Metrics.} Pair precision $B$, pair recall $R$ and $F1$; boundary exact, $\pm1$,
$\pm2$, $\pm4$ and mean endpoint error; multi-copy coverage, extra copies per pair and strict
retention; decision calls per pair, tokens and wall-clock latency, with feature time and memory
reported separately. A $B$--$R$ pair is always reported with its protocol, because the same
system can look strong under one evaluator and weak under another.

\paragraph{Cost.} The strict branch performs $MN/s^2$ coarse comparisons and, per track,
$O(L\cdot W)$ band cells with $W{=}25$. Recovery adds one RANSAC pass over the same anchors and
at most eight binary questions; boundary choice adds at most eight five-way questions. With
$B{=}1$ a pair incurs at most 16 calls. Token and latency accounting includes retries and
failed calls.

\section{Reproducibility and limitations}
\label{sec:s-repro}

\paragraph{Reproducibility.} The reference implementation is the public FastVCL code base at
the frozen commit used for the configuration table; thresholds are read from the configuration
file, not hard-coded in the text. The main paper and this supplement are built from the same
repository. The historical rows are copied from the stored workbook without editing; the new
ladder is specified in enough detail to be rerun, but it has not been executed.

\paragraph{Limitations.} (i)~No benchmark evidence for the new stages exists in this draft; the
ladder is a protocol, not a result. (ii)~Recovery cannot exceed the strict anchor pool, so a
copy absent from that pool is unreachable. (iii)~Boundary choice runs before dedupe, so part of
the budget can be spent on duplicates; the alternative order is a code change we did not make.
(iv)~Visual evidence is defined but not executed, so nothing here tests whether frames would
help. (v)~The historical diagnostics are single-workbook numbers and are not independently
reproduced.

\paragraph{Ethics.} The method localizes copies of user videos; it does not identify people or
retrieve originals beyond the provided reference. The interface sees numeric evidence, not
frames, in the version studied. No new dataset was collected.
