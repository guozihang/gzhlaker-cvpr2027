\section{Sampling properties and span bound}
\label{sec:s-sampling}

\paragraph{Nested grids.} With zero phases, a stride-8 grid samples a subset of stride 4,
which samples a subset of stride 2. A coarser plan therefore adds no coordinate but changes
each row's Top-$K$ competition and adds arithmetic. For $64\times64$ inputs, one direction
has $32^2=1{,}024$ grid pairs at stride 2 and $32^2+16^2+8^2=1{,}344$ for $\{2,4,8\}$. The
two are not equal-budget controls; both directions and tie rescans are additional.

\paragraph{Independent phases.} A synchronous shift $(p,p)$ only covers offsets with
$p_B-p_A\equiv0\pmod s$. Independent phase pairs $(p_A,p_B)$ tile the two-dimensional offset
and are not the same experiment. The current configuration refuses multi-scale combined with
non-default independent phases rather than silently scanning the product.

\paragraph{Span bound.} A track with $h$ anchors at distinct A times on one stride-$s$ grid
occupies at least
\begin{equation}
i_{\max}-i_{\min}+1\ge(h-1)s+1
\quad\Longleftrightarrow\quad
i_{\max}-i_{\min}\ge(h-1)s
\label{eq:s-shortbound}
\end{equation}
feature-index positions. A copy shorter than this cannot supply all $h$ anchor times wholly
within itself. This is an internal-support bound for one grid, not an impossibility theorem
for final detection: outside anchors, tube extension or merged phases may still produce a
candidate overlapping that copy. Top-$K$ partners at one A time are not independent temporal
support; counts must use distinct projected times.

\section{Implementation audit: deviations and consequences}
\label{sec:s-impl}

The main paper specifies the method; this section records where the current reference
implementation differs, so that a later reader does not mistake a prototype for the
specification.

\subsection{Notation, validity mask and output convention}
\label{sec:s-notation}

Rows are feature indices $i\in\{0,\dots,M-1\}$ and $j\in\{0,\dots,N-1\}$. A row is valid
when it is non-empty, finite and has norm above $\varepsilon=10^{-8}$:
\begin{equation}
\begin{aligned}
m_i^A&=\mathbf{1}[\operatorname{finite}(F_{A,i})\land\lVert F_{A,i}\rVert_2>\varepsilon],\\
\fA{i}&=\begin{cases}F_{A,i}/\lVert F_{A,i}\rVert_2,&m_i^A=1,\\ \mathbf{0},&m_i^A=0,\end{cases}
\end{aligned}
\end{equation}
with $m_j^B,\fB{j}$ analogous, and
$\Sim_{ij}=\langle\fA{i},\fB{j}\rangle$ only when both rows are valid (otherwise
$-\infty$). The norm is computed in a precision that avoids overflow; feature files are
checked finite at load, and the sparse, tube and segment stages share the constant. An
invalid row is never a match node, contributes no evidence and cannot start or end a
prediction. The output is a set of half-open interval pairs
$\mathcal{Y}=\{(a_s,b_s,a_e,b_e,q)\mid 0\le a_s<a_e\le M,\;0\le b_s<b_e\le N,\;q\in\mathbb{R}\}$;
$q$ is uncalibrated and coordinates are feature indices. A verified timestamp map is required
before calling an index a second or a source frame; this draft does not establish one.

\subsection{Local DP restart semantics}
\label{sec:s-dp}

The proposed recurrence is the zero-floored local-alignment equation in the main Method. The reference
implementation initializes a cell with no legal predecessor at $\max(0,r_{ij})$, but a cell
with a legal predecessor receives the continuation value \emph{unconditionally}, even when
that value is negative. Its documentation defends this as treating a weak frame as weak
evidence rather than as the absence of evidence. The two readings agree whenever all
evidence is strong. They differ in two regimes, which are the reason the choice is an
experimental variable:

The mechanism is not only the sign of the continuation. When a legal predecessor exists,
the prototype sets $H=\mathrm{own}+\max_{\mathrm{pred}}(H_{\mathrm{pred}}-\lambda g)$ and
never compares with $\max(0,\mathrm{own})$; it also lets a negative $H$ cell serve as a
predecessor. A negative cell cannot start a traceback (its backpointer is cleared), but it
can be the first node of a later path and force a strong frame to pay the deficit. The
proposed recurrence restarts at the current cell and accepts only predecessors with $H>0$.

In the first input, the prototype's accumulated score after the weak prefix is negative at
every copy row, so the global maximum is 0 and no prediction is produced. In the second
input, the prototype finds the first block; after blocking its path, the second block is
still reached only through the unblocked weak gap and remains negative, so the second copy is
lost. The zero-floored recurrence restarts at the first copy row (case 1) and at the second
copy block (case 2). The mirror risk also exists: with a very short accumulated score, a
single weak frame can trigger an early restart. The zero floor is therefore not universally
better; E3 measures both on real candidates.

The existing unit test named ``restarts after a negative run'' does not distinguish the two
semantics: its global maximum lies in the first positive block, so both implementations pass
while the second block remains negative. Two further diagnostics are required before the
default is fixed: a long weak prefix followed by a true copy, and two same-track copies with
a long weak gap at the DP layer.

\subsection{Validity threshold, finite rows and the RANSAC draw}
\label{sec:s-valid}

The main text uses $\varepsilon=10^{-8}$; the prototype's shared constant is also $10^{-8}$
(\texttt{MIN\_ROW\_NORM}), used by the sparse search and the tube. Segment extraction
consumes the resulting node-valid mask. An
earlier draft wrote $10^{-12}$, which would have made rows with norms in
$(10^{-12},10^{-8}]$ valid on paper and invalid in code. The threshold is now aligned to the
implementation. Feature files are checked for non-finite values when loaded; the explicit
finite term in the mask keeps the definition safe for direct callers. The normalization
helper itself does not test \texttt{isfinite}: an \texttt{Inf} row has an infinite norm,
compares above the threshold, and divides to \texttt{NaN}. This is a helper-level gap to
harden before the helper is exposed as a public API; the pipeline itself rejects the file at
load.

The RANSAC draw is two anchors at distinct A coordinates. The code does not impose a minimum
A separation at draw time; the accepted run must still satisfy the A span
($L^A_{\min}=4$), the B span ($L^B_{\min}=8$) and the distinct-support minimum
($h_{\min}=5$). A minimum draw separation would be a new constraint, not a description of
the current algorithm.

\subsection{Predecessor addressing}
\label{sec:s-pred}

The ideal recurrence addresses the predecessor by its band-relative column
$\delta_u=(j-\Delta j)-c_r(i-\Delta i)$, which is $O(1)$ per step. The reference
implementation enumerates every column of the predecessor row for the non-diagonal steps and
filters by the actual index difference; that is $O(W_r)$ per cell and $O(P_rL_rW_r^2)$ per
tube. The two are reported separately in the complexity section and in E5. A wall-clock
number is only meaningful with the implementation named.

\subsection{Coarse-stage dot products}
\label{sec:s-dots}

The implementation performs a forward Top-$K$ scan, a backward Top-$K$ scan and, when ties
touch the $K$-th position, a re-scan of the tie group. The executed count is therefore close
to twice the one-direction grid size plus tie work. The efficiency comparisons use the
executed count, not the idealized one-pass count. The memory budget is a per-stage plan
computed before allocation; a budget violation is an explicit error, not a silent fallback.

\subsection{Sampling-plan interactions}
\label{sec:s-plan}

Multi-scale plans and non-default independent-phase plans are implemented, but their
combination is refused by the configuration rather than silently scanning the product. The
formal default is a single zero-phase stride-4 grid with Top-1 mutual matching. Multi-scale
must be compared with a single fine grid at the same dot-product budget; without that control,
a gain can be a budget increase rather than a scale effect.

\subsection{Segment post-processing}
\label{sec:s-seg}

A path is smoothed with a centered window of 3; cosines are clamped below zero before
edge-padded smoothing; nodes at or above $\tau_{\mathrm{seg}}=0.6$ are strong evidence. Runs
split when the number of intervening A indices exceeds $g_{\mathrm{low}}=2$ (equivalently the
index difference exceeds 3); weak leading/trailing nodes are trimmed; a run must reach 3
frames on A, 4 on B and contain two anchor entries. Two details are easy to misread. First,
\texttt{boundary\_margin} expands the strong span by that many \emph{matched path rows}
before endpoints are taken; it is not a feature-index margin, and on a local-DP path two rows
need not be two original A indices. The reference value is 2; the proposed Method uses zero
output margin. Second, the support count is over stored A-anchor entries in an A-only
interval, not distinct A times inside both intervals; with Top-$K>1$ the same A time can
contribute several entries. The proposed score uses the distinct-both-axes rule. These are
unresolved implementation differences, not completed fixes.

The prototype score is
$0.7\cdot\operatorname{clip}(\bar s,0,1)+0.3\cdot\min(1,N_{\mathrm{seg}}/
\max(1,L_A/\bar\Delta_A))$, where $N_{\mathrm{seg}}$ is the stored-entry count above. It is
not a learned objectness and is not calibrated against one. The prototype writes all
post-deduplication segments with scores; the confidence threshold is applied by the
evaluator (legacy mode: $q>c$, and $c=0$ skips both filtering and integer conversion). The
proposed Method should not be read as thresholding inside the core pipeline.

\subsection{A-range fallback when $e_A=0$}
\label{sec:s-arange}

The tube equation uses the A extension \(e_A\). In the code, \texttt{candidate\_a\_range}
pads by \texttt{half\_width + margin} when no explicit range is supplied, and the refinement
call supplies an explicit range only when \texttt{extension\_a>0}. With $w_r=12$ and margin
2, an $e_A=0$ run would therefore scan 14 extra A positions on each side rather than zero.
An E4 row that varies \(e_A\) must pass an explicit A range for the zero-extension point, or
it changes two factors. The formal configuration uses $e_A=16$, for which the code and the
equation agree.

\section{Metric details}
\label{sec:s-metric}

\paragraph{Product, not minimum.}
For a pair with predictions $P_k$ and GT $G_l$, the official per-pair precision is the
product of the two axis coverage ratios (the metric equation in the main Experiments). The union is taken over
the non-empty intersections of each prediction with all GT boxes, separately on each axis;
the denominator is the sum of the prediction lengths on that axis. Recall is symmetric. The
two-axis minimum is used only for de-duplicating our own predictions. A system that covers the
right query interval but the wrong reference interval receives a product near zero, which is
the intended behaviour.

\paragraph{Sentinel exclusion.}
The official dataset aggregate drops every per-pair value exactly equal to 1. The degenerate
cases are: empty prediction with non-empty GT ($P=1$ sentinel, $R=0$); non-empty prediction
with empty GT ($P=0$, $R=1$ sentinel); both empty ($P=R=1$). For nonempty inputs each axis denominator adds $10^{-6}$, so ordinary perfect overlap
scores slightly below 1 and is retained. For example, identical $10$ by $20$ intervals
give $(10/(10+10^{-6}))(20/(20+10^{-6}))\approx0.99999985$.
Equality filtering remains dtype-dependent and must follow the source evaluator. The implementation therefore reports
\texttt{excluded\_precision\_eq\_1} and \texttt{excluded\_recall\_eq\_1}, and we preserve the
behaviour for comparability instead of silently ``fixing'' it. A cleaned version would change
the numbers and must be a separate protocol, not a drop-in replacement.

\paragraph{Four denominators.}
For a run, print \texttt{n\_expected} (list size), \texttt{n\_processed}
(\textsc{ok}+\textsc{empty}), \texttt{n\_precision\_denom}=$|\{p:P_p\neq1\}|$ and
\texttt{n\_recall\_denom}=$|\{p:R_p\neq1\}|$. The last two are the true macro denominators;
record them directly from the evaluator; do not infer them from a directory name or
rounded metric values. Ordinary nonempty perfect matches are not sentinel cases. Also print \texttt{n\_pairs\_with\_gt},
\texttt{n\_pairs\_with\_pred}, \texttt{n\_pairs\_with\_gt\_and\_pred},
\texttt{n\_error}, \texttt{n\_skipped} and the threshold used. A run whose status file does
not account for every selected pair is not admissible.

\paragraph{Negative-pair FAR.}
The negative FAR is the fraction of the 27,315 key-missing test pairs with at least one
prediction. It is not defined on the validation split, which has no negatives. The official
macro mean is not a substitute: a correctly rejected negative pair has $P=R=1$ and is dropped
from both means, so correct rejections do not enter the reported F1 at all. This is why the
paper reports FAR separately.

\section{Diagnostics and the augmented-system table}
\label{sec:s-diagnostics}

\paragraph{Candidate recall.}
A candidate is counted as covering a GT box when the axis-aligned tube envelope and the GT
box have minimum axis IoU at least $0.5$. An empty tube has no envelope and cannot cover.
Report the valid-GT denominator, exclusions, and the count by GT duration buckets
$<15$, $[15,60)$ and $\ge60$ feature indices. This is a proposal-box diagnostic; it does not
prove that a legal path exists or that a frame correspondence is correct.

\paragraph{Boundary MAE.}
Average the four endpoint errors after maximum-cardinality one-to-one matching at minimum
axis IoU $0.5$, then maximum total min-IoU, then deterministic id ties. Report each method's
matched count, its recall over the valid GT, and a common-GT cohort used for paired
differences. A lower MAE obtained only by losing hard matches is not an improvement.

\section{Evaluator parity check}
\label{sec:s-parity}

The port in \texttt{fastvcl/evaluate.py} was compared with the reference
\texttt{metric/eval.py} on synthetic boxes only. The check contains 11 hand-built cases
(identical, partial, disjoint, empty prediction, empty GT, both empty, multiple boxes,
overlapping predictions, touching intervals, float coordinates) and 200 deterministic random
cases with 0--3 predictions and 0--3 GT boxes.

Results:

\begin{itemize}
\item per-pair precision and recall: \textbf{211/211 exact}, maximum absolute difference
  $0.0$;
\item macro precision/recall and the exact-1 sentinel counts: identical on a synthetic
  result dictionary;
\item a five-row end-to-end accounting case: 4 scored pairs, 1 excluded \textsc{error},
  $|D_P|=|D_R|=2$, and two excluded exact-1 values per mean;
\item ordinary nonempty perfect overlap is retained at
  $0.9999998500000175$, not filtered as a sentinel;
\item the legacy \texttt{conf=0} branch performs neither score filtering nor integer
  truncation.
\end{itemize}

This is a \emph{function-level} parity result. It does not read the VCSL feature files, GT
JSON or a prediction file, and it does not certify the full evaluator entry point or the
official dataset score. The reference's bare \texttt{except: []} branch for malformed
predictions is deliberately not ported: the port refuses malformed input instead of
converting it to an empty prediction, which is the safer accounting rule.

\section{Dataset composition and GT anomalies}
\label{sec:s-data}

The local VCSL copy has 12,254 feature files (4,388,241,152 bytes), 97,033 training pairs,
41,798 validation pairs and 54,630 test pairs. Validation is 100\% positive; the test split
contains 27,315 key-missing pairs, treated as negatives. The CSV hashes are
\texttt{f7065467\ldots} (val), \texttt{b52c1b5f\ldots} (test) and
\texttt{47d492e2\ldots} (labels). Feature lengths range from 3 to 12,590 rows.

GT anomalies are kept, counted and never used to adjust candidates or predictions. In
validation, 60 intervals in 59 pairs extend beyond the feature length (maximum excess 108
indices) and 4 intervals are zero-length or reversed. In test, 8 intervals are out of range
and 45 are degenerate. A cleaned-subset analysis, if performed, must be frozen separately and
must not be presented as the official metric. The old data shipped next to a reference
implementation (55,530 pairs, 27,765 keys) is a different release and must not be mixed with
these files.

\section{Protocol details}
\label{sec:s-protocol}

\paragraph{Iso-budget comparison (E2).}
The budget is the executed number of dot products, not a nominal stride. For a zero-phase grid of stride $s$ with all rows valid, the one-direction count is
$\lceil M/s\rceil\lceil N/s\rceil$; the executed count
including the two directions and tie passes is read from the run log. A multi-scale or
multi-phase configuration is compared with a single fine grid whose executed count matches it
within a pre-declared tolerance. Exact equality may be unavailable for discrete grids;
in that case report the realized budgets without an iso-budget claim. For $M=N=64$,
stride 2 scores 1,024 grid pairs, while $\{2,4,8\}$ scores 1,344 before directional
rescans. Candidate recall and latency are plotted against executed count.

\paragraph{Single-factor rows (E4).}
Each row changes one item relative to the reference configuration. The RANSAC seed is derived
from the global seed and the pair id, so reruns are identical. The headline rows are repeated
with five seeds; the standard deviation is reported. A ``no geometry'' row is implemented as
a local-window proposal around the highest-scoring anchor clusters at the same dot-product
budget, never as ``skip fitting and output zero predictions''.

\paragraph{Timing (E5).}
Start: raw features resident in CPU memory, operators initialized. End: five-column
predictions exist in memory. Included: normalization, masking, tiling, transfers, sparse
matching, RANSAC, tube construction, band similarity, DP, traceback, post-processing and
in-memory serialization. Excluded and reported separately: feature file I/O, result export,
process initialization, video decoding and ISC extraction. Warm-up at least once, then at
least three measured rounds; profiling off; GPU timing synchronized at both ends; CPU threads
and GPU model reported.

\paragraph{TransVCL chunk timing.}
Measure all chunk pairs and assembly within the video-pair wall boundary, then compute
mean/P50/P95 over video pairs. A sum of model-forward times alone excludes preprocessing,
transfers or assembly and is not the primary pair latency.
Report the number of chunk pairs and the maximum chunk size. A single-chunk time is not a
video-pair time.

\section{Two budgeted decision points: full specification}
\label{sec:s-decisions}

\paragraph{Scope and status.}
This section records the specification summarized in the main Method. It is
\textsc{proposed}: no visual backend, verified frame map or action threshold has been
validated, and no result in this paper uses the layer. The core specification and its known
deviations from the prototype are unchanged. The branch is one model with one question
interface, inserted before geometric fitting (anchor filtering) and after segment extraction
(fragment fusion). It is outside the fixed-feature core comparison.

\begin{algorithm}[h]
\caption{FastVCL with two optional decision hooks (one pair)}
\label{alg:s-decisions}
\begin{algorithmic}[1]
\Require $F_A,F_B$; core configuration; mode $m\in\{\textsc{off},\textsc{shadow},\textsc{on}\}$; budget $B$
\Ensure $\mathcal{Y}=\{(a_s,b_s,a_e,b_e,q)\}$
\State compute valid rows and unit features
\State $\Anch_0\gets$ mutual Top-$K_{\rm nn}$ anchors, de-duplicated and capped
\State $\Anch_1\gets\Anch_0$
\If{$m\ne\textsc{off}$}
  \State $\Anch_1\gets$AnchorFilter$(\Anch_0,B_A)$ \Comment{log only in shadow}
\EndIf
\State $\mathcal{R}\gets$ multi-track RANSAC on $\Anch_1$; split and re-validate
\State $\mathcal{C}_0\gets\emptyset$
\ForAll{tracks $r$}
  \State build finite tube; run local DP on unblocked valid cells
  \For{$p=1$ \textbf{to} $P_r$}
    \If{no positive score} \State \textbf{break} \EndIf
    \State backtrace, trim and extract segments; add to $\mathcal{C}_0$; block matched cells
  \EndFor
\EndFor
\State $\mathcal{C}_0\gets$ filter by duration/support; score by the core rule
\State $\mathcal{C}\gets\mathcal{C}_0$
\If{$m\ne\textsc{off}$}
  \State $\mathcal{C}\gets$Fusion$(\mathcal{C}_0,B_F)$ \Comment{log only in shadow}
\EndIf
\State $\mathcal{Y}\gets$ score-ordered de-duplication; apply cap
\State \Return $\mathcal{Y}$ \Comment{possibly empty}
\end{algorithmic}
\end{algorithm}

\paragraph{Items, evidence boards and prompt.}
An item is either an anchor $a=(i,j)$ or an ordered segment pair $(c_u,c_v)$. For an anchor,
the board places up to three A images and three B images: the matched index and the nearest
sampled neighbours on each side, ordered by time. Each tile header records video side,
timestamp, feature index, cell id and question id. For a segment pair the board adds the two
fragment interiors, both boundary sides and, when obtainable, frames inside the gap; an
anchor board uses at most 3 paired positions and a segment board at most 5, i.e.\ 6 and 10
source frames respectively. Overlapping positions are de-duplicated and a missing frame is
marked missing rather than replaced by a neighbour from another time. Boards are built only
from original frames through a verified index-to-frame map; if the map is missing, the stage
returns \textsc{unavailable} and never fabricates an image. Sampling offsets, crop,
resolution, padding and missing-frame policy are frozen in the manifest.

The anchor prompt asks whether the two sides show the same underlying footage, explicitly
allowing crop, speed change, overlay and re-encoding and explicitly rejecting topical, person
or action similarity. The segment prompt asks whether two fragments are parts of one
continuous copy and whether the proposed connection interval is covered by that copy. Options
are fixed and ordered. Raw candidate logits or scores, option order, normalisation and the
adapter/readout revision are stored; free-form JSON is a separate control. Generated
rationales may be logged but are never parsed for automatic action.

\paragraph{Anchor set, competitor margin and selector.}
$\Anch_0$ is the anchor set after coordinate de-duplication and the original cap; no selector
may pre-delete it. Let $\mathcal C_B(i)$ be the B coordinates compared with A index $i$ in any
executed plan, merged by original coordinate and de-duplicated, and let $\mathcal C_A(j)$ be
analogous. For an anchor $(i,j)$,
\begin{equation}
\begin{aligned}
\mu_B(i,j)&=\Sim_{ij}-\max_{j'\in\mathcal C_B(i)\setminus\{j\}}\Sim_{ij'},\\
\mu_A(i,j)&=\Sim_{ij}-\max_{i'\in\mathcal C_A(j)\setminus\{i\}}\Sim_{i'j},
\end{aligned}
\label{eq:s-margin}
\end{equation}
with a side marked \emph{missing} when its competitor set is empty, and
$\mu=\min(\mu_A,\mu_B)$ only when both sides exist. This compares the current match with its
strongest competitor on each axis, rather than always subtracting the second-ranked partner.
The competitor pool is the union of executed comparisons for the same coordinate across plans;
no unrecorded full-resolution scan is added. A missing side is logged and the margin enters
the selector as the neutral rank $1/2$. This is an initial rule, not a validated optimum.
Top-$K_{\rm nn}=1/2/3$, score ties, a singleton partner pool and a coordinate repeated across
plans therefore have explicit outputs.

Anchors are grouped on a fixed two-dimensional grid of width twice the finest sampling stride,
and groups are visited round-robin so one repeated-texture cluster cannot exhaust the budget.
Inside a group,
\begin{equation}
\pi(a)=\tfrac12\operatorname{rank}(-\mu(a))+\tfrac12\operatorname{rank}(\rho(a)),
\label{eq:s-selector}
\end{equation}
where both ranks are normalised to $[0,1]$ inside $\Anch_0$, $\rho(a)$ is the normalised
residual to a local pre-fit line, and larger is preferred. A missing margin, missing geometry
or singleton pool contributes the neutral value $1/2$; ties use $(i,j)$; random controls use a
fixed seed. The selector is \textsc{selection-only}: an unselected, unqueried or failed anchor
must be identical to its core state, checked item by item. Group width and ordering may be
changed only on \texttt{dev\_design}.

\paragraph{Action rule, thresholds and modes.}
With queried set $\mathcal Q$ and scores $p^{\mathrm{anc}}_N,p^{\mathrm{anc}}_C,p^{\mathrm{anc}}_U$,
\begin{equation}
\begin{aligned}
D(a)=&\,\mathbf{1}[a\in\mathcal Q]\mathbf{1}[\text{verified}]\\
&\cdot\mathbf{1}[p^{\mathrm{anc}}_N\ge\tau_A]
\mathbf{1}[p^{\mathrm{anc}}_N-\max(p^{\mathrm{anc}}_C,p^{\mathrm{anc}}_U)\ge\delta_A],
\end{aligned}
\label{eq:s-action-anchor}
\end{equation}
and $\Anch_1=\Anch_0\setminus\{a:D(a)=1\}$. \texttt{COPY}, \texttt{UNCERTAIN}, unselected,
over-budget and failed anchors keep their coordinates and weight; the prototype rule that
multiplies \texttt{COPY} weights by $1.25$ is not inherited. Tracks are refitted on
$\Anch_1$ and dual-axis support/span are revalidated; the sequence
$\Anch_0\to\Anch_1\to$ tracks $\to$ tubes and each deletion reason are logged. Development
grids are $\tau_A\in\{0.90,0.95,0.98\}$, $\delta_A\in\{0.15,0.30\}$; they are operating
points, not calibrated probabilities, frozen before test. The first mode is \textsc{shadow}:
it logs decisions but returns $\Anch_1=\Anch_0$ and must match the core output item by item.
\textsc{off} bypasses the branch. In \textsc{on} mode only $D(a)=1$ removes an anchor, and a
single abstention or failure promises only that item's fallback, not global equality.

\paragraph{Fusion edges.}
$\mathcal C_0$ is the core candidate set after near-duplicate removal, retaining track ids,
matched nodes, distinct support and scores. A legal directed edge $(c_u,c_v)$ requires:
(i) consistent temporal order and disjointness in the first version,
$a_e^u\le a_s^v$ and $b_e^u\le b_s^v$; (ii) A and B gaps within development-frozen caps
$G_A,G_B$, with raw and normalised gaps recorded; (iii) per-direction boundary-map
compatibility -- the two A-to-B residuals $|m_u(a)-b|$ at $a\in\{a_s^v,a_e^v\}$ must each be
at most $\kappa_B$, and the two B-to-A residuals $|m_v^{-1}(b)-a|$ at
$b\in\{b_s^u,b_e^u\}$ each at most $\kappa_A$, where $m_u$ is $u$'s affine source map;
thresholds and inverse slopes must be finite, a degenerate or missing map makes the edge
unavailable, and a pooled maximum is never used; (iv) a connector from $(a_e^u,b_e^u)$ to
$(a_s^v,b_s^v)$ with slope in $[\alpha_{\min},\alpha_{\max}]$, where a zero gap is legal only
when both axes are zero; a single-axis zero gap has no finite connector slope and is
rejected. A pair with $\IoU_A\ge\theta_{\mathrm{dedup}}$ but
$\IoU_B<\theta_{\mathrm{dedup}}$ is the same A interval at a different B position, hence a
separate copy, and is excluded. Neighbours are generated deterministically with a
per-fragment cap, and the number of edges and truncations is recorded.

The first-version selector groups edges by the earlier fragment's A position on a grid of
width twice the finest stride and visits groups round-robin. Within a group it sorts by the
normalized gap
$\tilde g=\max(\mathrm{gap}_A/G_A,\mathrm{gap}_B/G_B)$, then by the maximum
threshold-normalized boundary-map error $\max(\max e_B/\kappa_B,\max e_A/\kappa_A)$, then by
$(c_u.\mathrm{id},c_v.\mathrm{id})$, and selects at most $B_F$ edges; exhausted groups are
skipped. No learned benefit predictor is introduced.
The same-A/different-B exclusion, group tie rule and per-fragment cap are frozen in the
configuration.

\paragraph{Connection evidence.}
The connection check $\mathrm{Conn}$ is fixed before the model call. Its region
$R_e=[a_e^u-\eta_A,a_s^v+\eta_A)\times[b_e^u-\eta_B,b_s^v+\eta_B)$ is clipped to the video
bounds; if its area exceeds $L_cW_c$, the edge is marked unavailable and the truncation is
recorded rather than silently shrinking the region. Support nodes are the path nodes of $u$
with A index in $[a_e^u-\beta_A,a_e^u)$ and of $v$ with A index in
$[a_s^v,a_s^v+\beta_A)$; if either set is empty, $\mathrm{Conn}=0$. The DP that proposes
paths and the check that certifies a bridge are separate. Certification is initialized only
at valid support nodes of $u$: only positive seed scores are usable, no other cell can start
a path, and no cell can restart one. It propagates the declared steps of the local recurrence
with score $\Sim_{ij}-\tau_{\mathrm{conn}}$ while the cumulative score stays positive. A cell
merely adjacent to the right fragment is not sufficient: the backtraced path must start at a
left support node and end at a right support node, and both memberships are verified. Ties
are broken by score, then end coordinates, then step order. The single highest-scoring path
is tested for interval coverage, $\min(d_A/s_A,d_B/s_B)$ over the endpoint spans, and for
low-score runs counted on path nodes; skipped indices, invalid cells in the bounding box and
the number of path nodes, DP visits, predecessor evaluations and similarity evaluations are
logged separately. If the best path fails the quality test, the edge is rejected; this
conservative first version does not claim to enumerate all feasible paths. A reused path is
rechecked under the same endpoint, region, step and quality rules. Failure keeps the
fragments separate; the region is never enlarged until a path appears. All attempted and
failed cell visits are counted and charged to the connection term rather than reported as a
model call.

\paragraph{Action, merge scope and output.}
With geometric legality $G$,
\begin{equation}
\begin{aligned}
M(u,v)=&\,G(u,v)\land\mathrm{Conn}(u,v)\land[p^{\mathrm{fus}}_M\ge\tau_F]\\
&\land[p^{\mathrm{fus}}_M-\max(p^{\mathrm{fus}}_S,p^{\mathrm{fus}}_U)\ge\delta_F],
\end{aligned}
\label{eq:s-action-merge}
\end{equation}
and only $M=1$ merges. \texttt{KEEP\_SEPARATE}, \texttt{UNCERTAIN}, failure and budget
exhaustion retain both fragments. The first version merges only original disjoint pairs of
$\mathcal C_0$. Edges are processed in the stable order above, and a pair is eligible only
when neither member has been consumed. An accepted merge consumes exactly its two members,
creates no new edge, performs no second model call, and does not trigger set-level
re-verification or propagation to a third fragment. Endpoints are rebuilt from the merged
path nodes and de-duplicated anchors, and support and the core score are recomputed by the
main score rule; neither $\max(q_u,q_v)$ nor a product with the visual probability is used.
If reconstruction fails, the action is rejected and both members remain available; same-A/
different-B duplicates stay separate. Final min-axis-IoU de-duplication and the output cap
are applied last. Development grids are
$\tau_F\in\{0.90,0.95,0.98\}$, $\delta_F\in\{0.15,0.30\}$, selected separately from the
anchor grid; if no pair meets the risk and recall targets, fusion stays in shadow.

\paragraph{Mechanism accounting and required failure cases.}
The fusion experiment must report the number of correct fusion opportunities, the fraction
covered by legal edges, the $\mathrm{Conn}$ pass rate, and the number of questions actually
asked and actions executed. It must compare ``$\mathrm{Conn}$ only'' with
``$\mathrm{Conn}$ + visual'' on the same $G$, the same $\mathrm{Conn}$ and a fixed selected
edge set; otherwise edge-selection differences are misattributed to the model. If core
evidence is too weak for any correct bridge to pass $\mathrm{Conn}$, the visual branch has no
repair opportunity; if $\mathrm{Conn}$ already completes every safe merge, the model adds
cost without demonstrated benefit.

Coverage must include: same-source short gap; long real non-copy gap; similar scene from
different footage; the same A interval copied at multiple B positions; dual-axis order
conflict; speed change; a correct local decision followed by a wrong transitive merge; and
missing frames or budget exhaustion. Report correct merges, wrong bridges, missed merges,
boundary MAE, MAE on the common-GT cohort and full-set recall/F1; reducing the number of
output segments is not a benefit by itself.

\paragraph{Budget manager, cache and failure contract.}
Both stages share one budget $B\in\{0,4,8,12\}$ with default $B=12$;
$B_A=\lfloor2B/3\rfloor$ anchor questions and $B_F=B-B_A$ fusion questions. Unused anchor
budget may move to fusion once; fusion budget is never borrowed in advance, and starting the
second stage must not call a fresh pair initialisation. Let $q_A,q_F$ be the logical questions
actually asked, including cache hits; the contract is
$q_A\le\lfloor2B/3\rfloor$ and $q_A+q_F\le B$, so with at most 3 paired positions per anchor
question and 5 per fusion question,
$N_{\mathrm{paired}}\le3q_A+5q_F\le5B$ and
$N_{\mathrm{slots}}\le6q_A+10q_F\le10B$. The fixed allocation $3B_A+5B_F$ is a special
case, not the worst case: at $B=12$, transferring all eight anchor questions to fusion
permits 60 paired positions and 120 source-frame slots rather than 44. Physical executions,
unique and repeated frames, and decoded frames are recorded separately from logical
questions. Budget units count decisions including
cache hits; physical executions are recorded separately. A batch may contain several
questions: log questions, frames per question, unique and repeated frames, processed visual
tokens, input size, forward passes, visual encodings, cache hits, peak memory and elapsed
time. Retries are off by default; if enabled, at most one per question plus a predeclared
per-pair cap $R$, and the worst case $B+R$ is reported. An invalid option set, NaN/Inf score,
mismatched item id or corrupt record is a failure and never reaches an action threshold. The
cache key binds frame-content hashes, the index/time-map hash, question type, candidate
coordinates, layout and preprocessing, option order, prompt, and checkpoint/adapter/readout
revision. Failures are never cached as \texttt{NOT\_COPY} or \texttt{MERGE}. Visual/KV prefix
sharing is attempted only when frame sets, layout, resolution, prompt prefix and model
revision are identical, and the shared fraction is recorded; the two stages are sequential
and are not presented as one forward pass.

The engineering targets are a true-copy anchor-deletion rate of at most $1\%$, a
wrong-fusion rate of at most $1\%$ and a final recall drop of at most $0.5$ percentage
points. These are project targets to freeze, not guarantees. If $n$ independent Bernoulli
trials yield zero errors, the one-sided $95\%$ exact upper bound is
\begin{equation}
p_{\mathrm{upper}}=1-0.05^{1/n}.
\label{eq:s-binomial}
\end{equation}
For $n=150$ this is about $1.98\%$; for $n=299$ it is $0.997\%$; for $n=300$ it is $0.994\%$.
At least 299 zero-error effective trials are needed for the bound to be no larger than $1\%$.
The denominator must match the risk definition: 150 candidate edges do not usually produce
150 accepted fusions. The calculation assumes independent, identically distributed trials;
shared videos, fragments and source material violate this. Design/calibration/audit splits
are assigned by source-video connected component. Thresholds are selected on calibration and
frozen to an independent audit; the same data cannot both select and certify. Grouped
intervals must be declared in advance; an ordinary bootstrap can degenerate to a zero-width
interval under zero errors, so it cannot establish the target. When independent groups are
too few, the result is ``insufficient evidence''.

\section{Round-two design corrections and optional E6}
\label{sec:s-round2}
\paragraph{Baseline controls.}
The simple sparse-to-band baseline shares the grid, coarse matcher, RANSAC trial cap,
fixed tube width/extension, zero-floored step set, scoring and min-IoU output rule with the
core method. It omits the extra dual-axis support/span checks and gap splitting, and uses
one path per tube. Its inlier minimum still requires sufficient distinct A times for a line.
E1 matches configured caps and executed coarse work, not realized candidate counts.
E3 alone reuses identical serialized tracks/tubes, with hashes, for refinement comparisons.
Full-matrix DP changes the search domain and is not an indexing-only ablation.

\paragraph{Sampling bound and uncertainty.}
The lower bound $(h-1)s+1$ applies to the span of $h$ distinct anchors on one stride-$s$
grid. A short copy cannot supply that many internal anchor times, but outside anchors and
tube extension can still overlap it. It is not a universal no-detection theorem. Likewise,
gap splitting followed by validation can reduce the number of accepted tracks to zero.
For matched-boundary analysis report conditional MAE, matched counts, recall and the common
GT cohort across methods. Five RANSAC seeds measure fitting variability only. A paired
bootstrap needs a declared sampling unit and treatment of shared-video dependence; if this
cannot be justified, report descriptive variation without a significance claim.

\paragraph{E6 history.}
The earlier post-hoc, candidate-only E6 description is superseded by
Section~\ref{sec:s-decisions}. It is retained in the record only to avoid confusion: it
assumed a fixed candidate pool and a verifier-style accept/reject step, whereas the current
design inserts the model before fitting and after segment extraction and shares one budget.
Metrics on selected candidates alone remain insufficient, and an oracle verdict remains an
analysis ceiling, never a deployed policy.

\paragraph{Verification scope (round 3, historical).}
Three read-only checks were run in round 3. (i) The prototype's unit suite: 646 tests, 0
failures, 10 CUDA tests skipped because no GPU executed. (ii) Evaluator parity: 211 synthetic
cases, zero per-pair mismatch, identical macro and sentinel counts, and a five-row
status/accounting case (Section~\ref{sec:s-parity}). (iii) Eight contract probes on
hand-built bands: weak prefix, strong--weak--strong, two copies after blocking, invalid
cells, A-range fallback, ties-to-even rounding, margin 0/2, duplicate-versus-distinct support
and the segment gap boundary. These are semantics and accounting checks, not benchmark
results. They do not execute a VCSL pair, a model checkpoint or a GPU kernel, and they do not
certify an end-to-end evaluator file run. The proposed zero-floor recurrence, distinct
support, zero margin, new competitor margin, fusion selector and connection check remain
unimplemented in the prototype; the prototype continuation, stored-entry support and old
post-hoc verification path are the current behaviour.
